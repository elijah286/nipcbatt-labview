Scan Resources Names[Scan Resource Names]

    		DMM Resource Name[DMM Resource Name]

    Instrument Descriptor contains the resource name of the device to initialize.

    		DAQ Resource Physical Channels Names

    Physical Channel(s) specifies the names of the physical channels to use to create virtual channels. The DAQmx physical channel constant lists all physical channels on devices and modules installed in the system.

    To specify a range of physical channels, use a colon between two channel numbers or two physical channel names:

    DIO/port0/line0:4

    DIO/port0/line0:DIO/port0/line4

    You can specify channel ranges in reverse order:

    DIO/port0/line4:0

    Use commas to separate physical channel names and ranges in a list as follows:

    DIO/port0/line0, DIO/port0/line3:6

    If both physical and Global channels are provided, Global Channels will take precedence

Close all Shunts?

To measure Resistance list only, you can disable the option "Close all shunts" input, the DUT won't be powered since all shunts are open.

Relays Debounce Time (ms)

Define the timing specifications for the external relays debounce time. Typical default Value is 5 ms, but needs to be adjusted with you specific choice of external relays.

Execution Settings

Contains the values of all execution settings which were actually used by the driver during the measurement.

    		DMM Execution Settings

    This output cluster contains the values of all execution settings which were actually used by the driver during the measurement.

      		Absolute Resolution

      The smallest measurable increment that this DMM can detect.

      		Input Resistance (Ohm)

      The resistance presented by the DMM during the measurement.

      		Digits Resolution

      Indicates the number of digits displayed on the digital multimeter's readings.

      For example, for 5 digits, 00000 ~ 99999 can be displayed, but for 5 ½, this can be displayed when 000000 ~ 199999 are displayed. In other words, if ½ is used, it is used when the first digit is represented by only 0,1

      		Range

      The window of possible values that could be captured with this measurement.

      		Minimum Frequency (Hz)

      The minimum frequency that must be present for an accurate measurement.

      		Aperture Time (s)

      Specifies the length of time during which the DMM will measure the signal.

      		Auto Range Value

      If auto range was used, displays the range that was selected by the automatic range finder and then used in the measurement.

      		Settle Time (s)

      The time required for a measurement system to stabilize to a specified accuracy limit.

      		Function

      Displays the type of measurement that was executed.

Controls and Indicators

 Data to Write

Data to Write represents the digital data to be output. Each element in the array corresponds to a line in your task. The number of elements in the array must match the number of lines in the task.

Refer the Channel Identifiers to know the mapped channel lines.

    		Boolean

error out

error out passes error or warning information out of a VI to be used by other VIs.

Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code

    code is the error or warning code.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source

    source describes the origin of the error or warning.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

Channel Line Identifiers Measurement

Channel Identifiers returns the digital channels lines in the task.

Each line in this array maps linearly to the acquired digital states returned in Line States Output array.

    		Digital Data to write

Line States

Line States outputs the acquired states of digital lines configured in the DAQmx Task. Each element in this array maps linearly to a line in the task which is returned in Channel line identifier array

    		Boolean

Channel Identifiers Source

Channel Identifiers represents the corresponding digital output channels lines to which the generation data will be mapped linearly.

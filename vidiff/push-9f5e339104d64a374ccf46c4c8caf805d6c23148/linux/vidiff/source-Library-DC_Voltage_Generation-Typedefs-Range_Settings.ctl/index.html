 Range Settings

Range Settings

Specifies the minimum and maximum range settings for the analog output voltage channels.

    		Min Range(V)

    Min Range specifies the minimum value you expect to generate.

    This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

    		Max Range(V)

    Max Range specifies the maximum value you expect to generate.

    This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

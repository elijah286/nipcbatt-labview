 Channel Settings

Channel Settings contains range, terminal configuration and shunt resistor connected to the terminal for a specific channel or channels(s).

    		Active Channels

    Specifies the physical channel to modify.

    		Min Range

    Min Range specifies the minimum value you expect to measure.

    This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

    		Max Range

    Max Range specifies the maximum value you expect to measure.

    This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

    		Terminal Configuration

    Terminal Configuration specifies the input terminal configuration for the channel.

    		Shunt Resistor (ohms)

    Shunt Resistor specifies in ohms the resistance of an external shunt resistor connected to the output terminal.

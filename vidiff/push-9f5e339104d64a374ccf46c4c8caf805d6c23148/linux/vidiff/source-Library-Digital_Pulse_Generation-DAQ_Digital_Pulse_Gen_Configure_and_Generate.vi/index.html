Controls and Indicators

 Digital Pulse Settings

Digital Pulse Settings configures the high time, low time and number of pulses to generate a digital pulse signal

    		High Time (s)

    High Time is the amount of time the pulse is high in seconds.

    		Low Time (s)

    Low Time is the amount of time the pulse is low in seconds.

    		Number of Pulses

    Number of Pulses selects the number of output pulses that the counter generates.

DAQmx Task In[DAQmx Task In]

DAQmx Task In is the name of the task or a list of virtual channels to which the operation applies. If you provide a list of virtual channels, NI-DAQmx creates a task automatically.

error in[error in]

error in can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code[code]

    code is the error or warning code.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source[source]

    source describes the origin of the error or warning.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

error out[error out]

error out contains error information. If error in indicates that an error occurred before this VI or function ran, error out contains the same error information. Otherwise, error out describes the error status that this VI or function produces.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code[code]

    code is the error or warning code. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source[source]

    source identifies where and why an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

DAQmx Task Out[DAQmx Task Out]

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.

Actual Pulse Settings

Actual Pulse Settings returns the actual high time, low time and Generation time of generated digital signal from instrument

    		High Time (s)

    High Time is the actual amount of time the pulse is high in seconds.

    		Low Time (s)

    Low Time is the actual amount of time the pulse is low in seconds.

    		[Generation Time (s)]

    Generation Time Period returns the total generation time of digital signal in seconds which is based on the coerced value of the sample clock rate and the number of pulses.

    Generation time = Number Of Pulses*Time period

[Timebase Frequency (Hz)]

Timebase Frequency specifies the frequency of Counter timebase in Hz. Timebase is set based on the input configurations to support required frequency.

Supported frequency range to generate pulse depends on the available Timebase.

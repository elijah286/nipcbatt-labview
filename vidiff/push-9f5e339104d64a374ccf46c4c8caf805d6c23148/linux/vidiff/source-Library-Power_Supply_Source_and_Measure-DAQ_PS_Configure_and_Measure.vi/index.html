DAQ_Power Supply Source and Measure.lvlib:DAQ_PS Configure and Measure.vi

Configures, Initiate and fetch results for power supply measurements

Connector Pane

Front Panel

Controls and Indicators

 DAQmx Task In[DAQmx Task In]

DAQmx Task In refers to power supply task to be configured

Channel Settings[Channel Settings]

Configures power channel settings.

Applicable for "Configure & Measure" & "Configure Only"

Refer each control help for more details.

    		Voltage Setpoint(V)

    Voltage Setpoint specifies the constant output voltage, in volts.

    		Current Setpoint(A)

    Current Setpoint specifies the output current, in amperes.

    		Remote Sense

    Remote Sense specifies whether to use remote sense or local sense of the output voltage.

    Choose the appropriate one based on the connections to DUT.

    		Idle Output Behavior

    Idle Output Behavior specifies what should be the output after the end of power supply task.

    Disable output when Task stopped - There will be no output at the terminals since the output itself is disabled.

    Maintain Existing Value - The last output will be retained until next power supply task.

    		Enable Output?

    Specifies whether to enable or disable power module output.

error in[error in]

error in describes error conditions that occur before this VI or function runs.

    		status[status]

    status is TRUE (X) if an error occurred before this VI or function ran or FALSE (checkmark) to indicate a warning or that no error occurred before this VI or function ran. The default is FALSE.

    		code[code]

    code is the error or warning code. The default is 0. If status is TRUE, code is a negative error code. If status is FALSE, code is 0 or a warning code.

    		source[source]

    source identifies where an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

Timing and Trigger Settings[Timing and Trigger Settings]

Timing and Trigger Settings sets the timing and trigger settings for power supply task.

Applicable for "Configure & Measure" & "Configure Only"

Refer help of each settings to configure them appropriately.

    		Timing Settings

    Timing Settings sets the timing settings for power supply measurements which includes source clock source, sample rate, number of samples and sample timing engine to measure power measurements.

    Applicable for "Configure & Measure" & "Configure Only"

    Refer below scenario that will help in selecting appropriate values for Sample Rate and Number of Samples.

    Total acquisition time is based on sample rate and no of samples given.

    Acquisition time = Number Of Samples/Sample rate

    For Fast measurements, set maximum sample rate possible for the given "Sample Clock Source" input and assign smaller "Number of Samples" to capture. Minumum value for Number of Samples is 2

    For Precise measurements, assign higher "Number of Samples" to capture. Eg. 1000

    Refer help for each controls for more details.

      		Sample Clock Source

      Sample Clock Source specifies the source terminal of the Sample Clock.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible sample clock sources.

      		Sample Rate (Hz)

      Sample Rate specifies the sampling rate in samples per channel per second. If you use an external source for the Sample Clock, set this input to the maximum expected rate of that clock.

      		Number of Samples

      Number of Samples specifies the number of samples to read.

      		Sample Timing Engine

      Sample Timing Engine specifies which timing engine to use for the task. Choose Auto to let the instrument use the default one.

    		Trigger Settings

    Trigger Settings configures the power measurement to start aquisition on the configured trigger.

    Applicable for "Configure & Measure" & "Configure Only"

    Select No Trigger in case of immediate aquisition. Skip Digital Start Trigger Source and Digital Start Trigger Edge

    Select Digital Start for triggered aquisition. Required Fields: Digital Start Trigger Source and Digital Start Trigger Edge

      		Trigger Select

      The Trigger Select control selects which trigger type you wish to use. Depending on the option that is currently selected, when you run the VI your task will configure the desired trigger type.

      Note that not all hardware supports triggering--refer to your device documentation for more info.

      		[Digital Start Trigger Source]

      Digital Start Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

      		[Digital Start Trigger Edge]

      Digital Start Trigger Edge specifies on which edge of the digital signal to start acquiring or generating samples.

Execution Settings[Execution Settings]

Execution Settings specifies which set of operations to execute and skip/execute measurements at the end

    		Execution option[Execution option]

    Execution Option specifies operations to execute.

    Configure and Measure - Executes the complete

    VI which configures the instrument and performs the

    measurement

    Configure Only - Sets the configuration to the

    instrument and Initiate but skips the fetch and measure. This

    is useful for external trigger usecases where the channel can

    be set to wait for the trigger and the execution can followed

    by that assets the trigger

    Measure Only - Fetch the data captured in the

    instrument and performs the processing to return the

    measurements. Please note that Measure only cannot be

    repeated without preceding with the "Configure Only"

    		Skip Analysis?[Skip Analysis?]

    Skip Analysis? configures to use the inbuilt measurement or just fetch the raw captured data for external analysis.

Acquisition Time (s)[Acquisition Time (s)]

Acquisition Time Period returns the total acquisition time by the instrument in seconds which is based on the coerced value of the sample clock rate and the number of samples.

Acquisition time = Number Of Samples/Sample rate

For Fast measurements, set maximum sample rate possible

for the given "Sample Clock Source" input and assign smaller

"Number of Samples" to capture.

Minimum value for Number of Samples is 2

For Precise measurements, assign higher "Number of Samples" to capture. Eg. 1000.

NOTE: Acquisition Time of Measurement is updated only during Configure Only and Configure & Measure calls, not in Measure Only call.

DAQmx Task Out[DAQmx Task Out]

DAQmx Task Out refers to power supply task. The task contains updated configuration settings.

Voltage Waveforms[Voltage Waveforms]

Voltage Waveforms displays the most recent acquired data from power supply voltage. If the output is disabled, the data read will be NaN, and the graph will be blank for those points.

Current Waveforms[Current Waveforms]

Current Waveforms displays the most recent acquired data for power supply current. If the output is disabled, the data read will be NaN, and the graph will be blank for those points.

Power Measurements[Power Measurements]

Power measurements holds the derived measurement data from the captured voltage and current waveforms

    		Max Voltage Level(V)[Max Voltage Level(V)]

    Maximum voltage level supplied by the power supply in Volts

    		Max Current Level(A)[Max Current Level(A)]

    Maximum current level supplied by the power supply in Amperes.

    		Max Power(W)[Max Power(W)]

    Maximum power generated by the power supply in Watts

    		Average Power (W)[Average Power (W)]

    Average power generated by the power supply in Watts

error out[error out]

error out contains error information. If error in indicates that an error occurred before this VI or function ran, error out contains the same error information. Otherwise, error out describes the error status that this VI or function produces.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code[code]

    code is the error or warning code. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source[source]

    source identifies where and why an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

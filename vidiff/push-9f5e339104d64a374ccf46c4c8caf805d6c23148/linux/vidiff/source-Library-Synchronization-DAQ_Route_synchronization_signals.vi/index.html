DAQ_Synchronization.lvlib:DAQ_Route synchronization signals.vi

Route synchronization signals VI can be used to route signal between specified signal and output terminal.

The specified source signal and output terminal can be on different devices as long as a connecting public bus, such as TestScale backplane, connects the devices. These routes are embedded in a task. When the task is committed, the route is committed. When the task is cleared, the route is unreserved.

Routing paths

Routing paths specifies the list of paths between exported signal and output terminals where routing actions are performed.

    		Routing Path

    Routing Path routes a control signal to the specified output terminal. The route can carry a variety of digital signals, such as triggers and clocks.

      		Signal

      Signal specifies the device signal to export.

      The available options are,

      Sample Clock - Clock the device uses to time each sample

      Start Trigger - Trigger that begins a measurement or generation

      These Signals are associated with the DAQmx Task provided in the input. Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible signals for routing.

      		Output Terminal

      Output Terminal is the destination of the exported signal.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible terminals for routing.

DAQmx Task In

DAQmx Task In is the name of the task or a list of virtual channels to which the operation applies.

error out[error out]

error out contains error information. If error in indicates that an error occurred before this VI or function ran, error out contains the same error information. Otherwise, error out describes the error status that this VI or function produces.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code[code]

    code is the error or warning code. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source[source]

    source identifies where and why an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

DAQmx Task Out

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.

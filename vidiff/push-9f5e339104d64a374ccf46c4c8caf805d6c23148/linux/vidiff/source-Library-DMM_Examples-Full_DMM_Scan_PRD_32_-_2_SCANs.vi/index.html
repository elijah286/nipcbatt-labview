Execution Settings

Contains the values of all execution settings which were actually used by the driver during the measurement.

    		DMM Execution Settings

    This output cluster contains the values of all execution settings which were actually used by the driver during the measurement.

      		Absolute Resolution

      The smallest measurable increment that this DMM can detect.

      		Input Resistance (Ohm)

      The resistance presented by the DMM during the measurement.

      		Digits Resolution

      Indicates the number of digits displayed on the digital multimeter's readings.

      For example, for 5 digits, 00000 ~ 99999 can be displayed, but for 5 ½, this can be displayed when 000000 ~ 199999 are displayed. In other words, if ½ is used, it is used when the first digit is represented by only 0,1

      		Range

      The window of possible values that could be captured with this measurement.

      		Minimum Frequency (Hz)

      The minimum frequency that must be present for an accurate measurement.

      		Aperture Time (s)

      Specifies the length of time during which the DMM will measure the signal.

      		Auto Range Value

      If auto range was used, displays the range that was selected by the automatic range finder and then used in the measurement.

      		Settle Time (s)

      The time required for a measurement system to stabilize to a specified accuracy limit.

      		Function

      Displays the type of measurement that was executed.

Total Scan Time (s)

Total Scan Time including relays debounce time, aperture and settling time of each individual measurements in the scan list.

Switches Characteristics[Switches Characteristics]

Contains the Switches Characteristics in Max Voltage and Current.

Note: only if the NI Multiplexer use embedded relays. The values will be 0 for external custom relays as for the NI 2567 Relay Driver only.

    		MUX Characteristics[Mux Characteristics]

    Returns the maximum module switching characteristics.

    Switching voltage refers to the maximum signal voltage that the switch module can safely maintain.

    Switching current is the maximum rated current that can flow through the switch as it makes or breaks a contact. Switching active currents results in arcing that can damage the contacts of electromechanical relays.

    Max. DC Voltage (V) - Maximum DC voltage the module can support.

    Max. Switching DC Current (A) - Maximum DC Current the module can support when switching.

    Max. AC Voltage (V) - Maximum AC voltage the module can support.

    Max. Switching AC Current (A) - Maximum AC Current the module can support when switching.

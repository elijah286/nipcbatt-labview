DMM_Scan PXI RLY Driver 32V-16C.lvlib:Current Channels Array.vi

Checks if the channel is a current channel (channels 32 to 47) and provides chX+16 and comX+16 names for individual current shunt relay paths (48 to 63 will be reserved).

Returns if Channel 1 is part of a current channel mapping.

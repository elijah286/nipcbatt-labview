Switch_Static Digital Path Generation.lvlib:Switch_Static Dig Path Gen Configure and Generate.vi

Connects or disconnects a switch path between two specified channels on the NI Switch device from a boolean input. Multiplexers or individual relay switches can be controlled. Enables change of the default value for the maximum length of time to wait for all relays in the switch module to activate or deactivate. Indicates whether a path was valid before applying the Connect/Disconnect action.

Switch Handle In[Switch Handle In]

Switch Handle In - Identifies a NI-SWITCH Session.

Maximum Wait for Debouce Time[Maximum Wait for Debouce Time]

Maximum Wait for Debouce Time - Specifies the maximum length of time to wait for all relays in the switch module to activate or deactivate. If the specified time elapses before all relays activate or deactivate, a timeout error is returned.

Default value: 5000 (milliseconds)

Terminal and State Settings

Channel 1 - Specifies one of the channel names of the path to break. Pass the other channel names for the switch module.

Channel 2 - Specifies one of the channel names of the path to break. Pass the other channel name as Channel 1. Refer to Devices for valid channel names for the switch module.

Connect/Disconnect - Connects or disconnects the path from Channel 1 to Channel 2 according to the Topology initialized.

Path Status[Path Status]

Indicates whether a path was valid before applying the Connect/Disconnect action. Possible values include:

Path Available (1) - Indicates that the driver can create the path at this time.

Path Exists (2) - Indicates that the explicit path between the channels already exists.

Path Unsupported (3) - Indicates that the instrument is not capable of creating a path between the two channels.

Resource In Use (4) - Indicates that although the path is valid, the driver cannot create the path at this moment because the switch module is currently using one or more of the required channels to create another path. You must destroy the other path before creating this one.

Source Conflict (5) - Indicates that the instrument cannot create a path because both channels are connected to a different source channel.

Channel Not Available (6) - Indicates that the driver cannot create a path between the two channels because one of the channels is a configuration channel and thus unavailable for external connections.

Other (0) - Indicates another issue like an unknown channel or a previous error input. In this case check the error status message.

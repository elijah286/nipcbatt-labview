Controls and Indicators

 Cycles to capture

Cycles to capture specifies the number of PWM cycles to capture which are averaged to derive Digital PWM Measurements

Note: Low time for a single pulse cannot be determined as it might not have a clear ending (Rising edge). So, Minimum cycles required for PWM Measurement is 2.

Digital Pulse Settings

Digital Pulse Settings configures the high time, low time and number of pulses to generate a digital pulse signal

    		High Time (s)

    High Time is the amount of time the pulse is high in seconds.

    		Low Time (s)

    Low Time is the amount of time the pulse is low in seconds.

    		Number of Pulses

    Number of Pulses selects the number of output pulses that the counter generates.

error out

error out passes error or warning information out of a VI to be used by other VIs.

Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code

    code is the error or warning code.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source

    source describes the origin of the error or warning.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

Actual Cycles Captured

Actual Cycles Captured specifies the actual no. of cycles captured during the measurement.

NOTE: It is updated only during the Measure Only and Configure & Measure calls, not in Configure Only call.

Digital PWM Measurements

Digital PWM Measurements specifies the derived PWM measurements from the captured digital waveform. The PWM measurements include High Time(s), Low Time(s), Duty Cycle(%) and Frequency(Hz).

    		High Time (s)

    High Time (s) specifies the averaged time (in seconds) during which a pulse remains High in the PWM waveform.

    		Low Time (s)

    Low Time (s) specifies the averaged time (in seconds) during which a pulse remains Low in the PWM waveform.

    		Duty Cycle (%)

    Duty Cycle (%) specifies the averaged duty cycle (in percentage) measured in the PWM Waveform.

    Duty Cycle (%) = (High Time/Pulse Period)*100

    		Frequency (Hz)

    Frequency (Hz) specifies the frequency of the captured digital PWM waveform.

    Frequency (Hz) = 1 / Pulse Period (s)

Actual Pulse Settings

Actual Pulse Settings returns the actual high time, low time and Generation time of generated digital signal from instrument

    		High Time (s)

    High Time is the actual amount of time the pulse is high in seconds.

    		Low Time (s)

    Low Time is the actual amount of time the pulse is low in seconds.

    		[Generation Time (s)]

    Generation Time Period returns the total generation time of digital signal in seconds which is based on the coerced value of the sample clock rate and the number of pulses.

    Generation time = Number Of Pulses*Time period

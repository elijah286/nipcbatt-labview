Communication.lvlib:845x_SPI Read.vi

NOTE: This example is taken from ni845x driver examples located at C:\Program Files (x86)\National Instruments\LabVIEW <version>\examples\ni845x\845xEx.llb. More such examples can be found in the same location.

This example shows a more generalized way to use the SPI basic API to read data. It allows the user to change the following parameters: the endianness of the address bytes, and the number of bytes in an address.

The parameters will have the following effects:

Data Address Width: This will allow the user to specify the EEPROM Data Address as either 1 or 2 bytes.

Data Address Endianness: This control will change the ordering of the bytes in the EEPROM Data Address, note that this only has an effect if there are 2 bytes in the address.

For connection information see the NI-845x Hardware and Software manual and the manual for your specific SPI device.

Controls and Indicators

 Chip Select

This indicates the chip select line that will be asserted during the SPI transfer. This line should be connected to your EEPROM.

Clock Rate (kHz)

This is the clock rate in Hz of each SPI transfer. The Atmel AT25080A supports transfers up to 10 Mhz for a 3.3V Vcc. The default of 1 Mhz is within this range. Please consult the data sheet for other transfers rate options.

Number of Bytes to Read

This is the number of bytes to read. The AT25080 has a 32-byte page, but can read the entire memory (1024 bytes) in one operation, so that maximum number of bytes to read is 1024, but the default is a single page, or 32 bytes.

EEPROM Data Address

This is the address within the EEPROM where the data access will be started.

Device

This is the name of the device that you are using. This corresponds to the name of the USB device found in the Measurement and Automation Explorer (MAX). This can either be the complete name or based on an alias.

Data Address Endianness

it specifies the order of bytes followed for data address bytes

Data Address Width

It specifies the data address size to be used in I2C communications.

I/O Voltage Level

I/O Voltage Level specifies the voltage level that is driven on the bus during high output when the DIO driver type is Push-Pull. If you are doing digital input, this must be set to match the ouput level of your device in order to properly sense the correct voltages. Please consult your hardware documentation for more information on supported I/O Voltage Levels.

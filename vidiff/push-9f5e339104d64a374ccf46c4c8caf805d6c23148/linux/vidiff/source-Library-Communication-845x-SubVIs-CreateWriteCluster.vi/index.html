Communication.lvlib:CreateWriteCluster.vi

Calculates the correct EEPROM start addresses for multiple page writes.

NOTE: This VI is taken from ni845x driver examples located at C:\Program Files (x86)\National Instruments\LabVIEW <version>\examples\ni845x\845xEx.llb. More such examples can be found in the same location.

Connector Pane

Front Panel

Controls and Indicators

 Page Size in Bytes

Given data will be splitted to different pages based on this size while writing to the hardware.

EEPROM Starting Address

This is the address within the EEPROM where the data access will be started.

Number of Bytes to Write

This is the number of bytes to write. The 24LC512 has a 128-byte page, so the maximum number of bytes to write is 128.

Array of Write Cluster Information

EEPROM start addresses for multiple page writes.

      		Data Index

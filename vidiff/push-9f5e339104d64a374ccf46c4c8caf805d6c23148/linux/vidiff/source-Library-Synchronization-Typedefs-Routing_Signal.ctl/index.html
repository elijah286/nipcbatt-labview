DAQ_Synchronization.lvlib:Routing Signal.ctl

Routing Signal specifies the device signal to export.

The available options are,

Sample Clock - Clock the device uses to time each sample

Start Trigger - Trigger that begins a measurement or generation

Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible signals for routing.

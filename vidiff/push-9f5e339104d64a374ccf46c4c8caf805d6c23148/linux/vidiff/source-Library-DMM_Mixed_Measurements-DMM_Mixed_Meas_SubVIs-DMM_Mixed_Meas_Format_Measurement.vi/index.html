DMM_Mixed Measurement.lvlib:DMM Mixed Meas Format Measurement.vi

Converts the value measured by the niDMM Read into two output strings which contain the measurement and the correct units corresponding to the specific measurement.

Connector Pane

Front Panel

Controls and Indicators

 Function

The type of measurement to be executed. Appears here in integer form to serve as a selector for the enum containing the different functions.

Digits Resolution

Specifies the precision of the measurement in terms of the number of valid digits to include in the result.

Measured Value

The actual numerical measurement captured by the DMM. Will be formatted by this function to a string.

Analyzes the DC current waveform data to derive required DC-RMS current measurements

Front Panel

Controls and Indicators

 error in (no error)

error in describes error conditions that occur before this node runs. This input provides standard error in functionality.

    		status

    status is TRUE (X) if an error occurred before this node ran or FALSE (checkmark) to indicate a warning or that no error occurred before this node ran. The default is FALSE.

    		code

    code is the error or warning code. The default is 0.

    		source

    source specifies the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning. The default is an empty string.

DC and RMS Current Measurements

DC-RMS Measurements specifies Average DC Current and RMS Current measurements for each channels.

    		Average DC Current (A)

    Average DC Current is the average measured DC current values. List contains values for each channels.

      		Average DC Current (A)

      Average DC Current is the average measured DC current values of the current waveform measured from a single channel.

    		RMS Current (A)

    RMS Current is the measured RMS value of the measured waveform. List contains values for each channels.

      		RMS Current (A)

      RMS Current is the measured RMS value of the current waveform measured from a single channel.

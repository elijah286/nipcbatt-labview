 Scan Resources Names[Scan Resources Names]

    		DMM Resource Name[DMM Resource Name]

    Instrument Descriptor contains the resource name of the device to initialize.

    		DAQ Resource Physical Channels Names

    Physical Channel(s) specifies the names of the physical channels to use to create virtual channels. The DAQmx physical channel constant lists all physical channels on devices and modules installed in the system.

    To specify a range of physical channels, use a colon between two channel numbers or two physical channel names:

    DIO/port0/line0:4

    DIO/port0/line0:DIO/port0/line4

    You can specify channel ranges in reverse order:

    DIO/port0/line4:0

    Use commas to separate physical channel names and ranges in a list as follows:

    DIO/port0/line0, DIO/port0/line3:6

    If both physical and Global channels are provided, Global Channels will take precedence

Channels Topology mapping[Channels Topology Mapping]

Control to input your Channels Topology Mapping. The declaration starts with the Voltage channels Min and Max, the Current channels Min and Max, and the N Shift for the Current Shunt to place in parallel of Current Channels. The N Shift is a relative position from the Min Current Channel.

    		Min Channel Voltage

    		Max Channel Voltage

    		Min Channel Current

    		Max Channel Current

    		N Shift Shunt to Min Channel Current

error out

If an error occurred during execution, the status indicator will be lit and an error code will be provided.

Right-click the error out control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status

    		code

    		source

Topology Mapping Output[Topology Mapping Output]

Topology Mapping Output is to easily check your Mapping declaration and save time to connect the appropriated DO channels lines of your device. It can help for maintenance and HW modifications.

For the Shunts channels, the link to the Current channel number is returned.

    		String

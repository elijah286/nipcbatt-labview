Communication.lvlib:845x_I2C Read.vi

NOTE: This example is taken from ni845x driver examples located at C:\Program Files (x86)\National Instruments\LabVIEW <version>\examples\ni845x\845xEx.llb. More such examples can be found in the same location.

This EEPROM example shows a more generalized way to use the I2C basic API to read data. It allows the user to change the following parameters: the endianness of the address bytes, and the number of bytes in an address.

The parameters will have the following effects:

Data Address Width: This will allow the user to specify the EEPROM Data Address as either 1 or 2 bytes.

Data Address Endianness: This control will change the ordering of the bytes in the EEPROM Data Address, note that this only has an effect if there are 2 bytes in the address.

Since the I2C SDA and SCL lines are open-drain, they must be pulled up to the required reference voltage of your slave by connecting an appropriate resistor (2k-5k) between SCL and your reference voltage and SDA and your reference voltage. For NI-845x Hardware that contain internal pull-ups, you can use these. Otherwise, you need to use external pullups.

For connection information see the NI-845x Hardware and Software manual and the manual for your specific EEPROM.

Controls and Indicators

 Device

This is the name of the device that you are using. This corresponds to the name of the USB device found in the Measurement and Automation Explorer (MAX). This can either be the complete name or based on an alias.

Address

This indicates the address of your device. The upper 4 bits of the address are fixed and give a default address of 0x50 for the Microchip 24LC512. The lower three bits can be adjusted by modifying the A0, A1, and A2 pins on the EEPROM. This example assumes that these pins are all grounded to provide the address of 0x50. If these lines are not all grounded, please change the address accordingly.

Clock Rate (kHz)

This is the clock rate in Hz of each I2C transfer. The Microchip 24LC512 supports transfers up to 400 kHz. The default of 100 kHz is within this range. Please consult the data sheet for other transfers rate options.

Number of Bytes to Read

This is the number of bytes to read. The 24LC512 has a 128-byte page, but can read the entire memory (64K) in one operation, so that maximum number of bytes to read is 64K, but the default is a single page, or 128 bytes.

EEPROM Data Address

This is the address within the EEPROM where the data access will be started.

Data Address Endianness

it specifies the order of bytes followed for data address bytes

Data Address Width

It specifies the data address size to be used in I2C communications.

Use Internal I2C Pullup Resistor

I2C Pullup Resistor configures the onboard pull-up resistors that connect the I2C SDA and SCL wires to the I/O Voltage Level (vRef). Please consult your hardware documentation for more information on supported onboard pull-up options.

I/O Voltage Level

I/O Voltage Level specifies the voltage level that is driven on the bus during high output when the DIO driver type is Push-Pull. If you are doing digital input, this must be set to match the ouput level of your device in order to properly sense the correct voltages. Please consult your hardware documentation for more information on supported I/O Voltage Levels.

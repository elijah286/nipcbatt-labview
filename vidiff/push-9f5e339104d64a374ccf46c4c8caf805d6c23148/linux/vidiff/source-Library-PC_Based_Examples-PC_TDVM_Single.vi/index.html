Controls and Indicators

 Voltage Waveforms[Voltage Waveforms]

Voltage Waveforms displays the most recent acquired data. If the output is disabled, the data read will be NaN, and the graph will be blank for those points.

error out[error out]

error out passes error or warning information out of a VI to be used by other VIs.

Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code[code]

    code is the error or warning code.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source[source]

    source describes the origin of the error or warning.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

Time Domain Measurements[Time Domain Measurements]

Displays the time domain measurements results.

NOTE: Captured waveform should contain more than one cycle to calculate Voltage Waveform Period (s) and Voltage Waveform duty cycle (%).

    		Mean DC Voltage (V)[Mean DC Voltage (V)]

    Mean DC value is the measured DC value in volts if the signal is in volts.

      		Mean DC Voltage (V)

      DC value is the measured DC value in volts if the signal is in volts.

    		Vpp Amplitude(V)[Vpp Amplitude(V)]

    Vpp Amplitude represents the peak to peak amplitude observed in the capture waveforms

      		Vpp Amplitude(V)

      amplitude is the difference between high state level and low state level.

    		Voltage Frequency(Hz)[Voltage Frequency(Hz)]

    Detected frequency is the frequency of the detected single tone in Hz.

      		Voltage frequency(Hz)

      detected frequency is the frequency of the detected single tone in Hz.

    		Voltage Waveform Period (s)[Voltage Waveform Period (s)]

    Voltage Waveform Period returns the time between adjacent mid ref level crossings in the same direction in seconds.

      		Voltage waveform period (s)

      period returns the time between adjacent mid ref level crossings in the same direction in seconds.

    		Voltage Waveform duty cycle (%)[Voltage Waveform duty cycle (%)]

    Duty cycle observed in the captured waveform in a fraction of a period.

      		Voltage Waveform duty cycle (%)

      duty cycle is a fraction of a period.

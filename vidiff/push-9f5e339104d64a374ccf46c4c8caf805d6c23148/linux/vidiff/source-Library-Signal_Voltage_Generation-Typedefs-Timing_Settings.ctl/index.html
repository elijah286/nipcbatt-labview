DAQ_Signal Voltage Generation.lvlib:Timing Settings.ctl

Timing Settings sets the timing details for signal voltage generation which includes source clock source, sample rate to generate signals.

For Fast generation, set maximum sample rate possible for the given "Sample Clock Source" input and assign smaller "Generation time" to generate. Min sample size is 2. For better resolution, configure the instrument to generate more samples eg. 1000 samples. Number of samples can be calculated from Generation time(s)/Sample rate(Fs).

 Timing Settings

Timing Settings sets the timing details for signal voltage generation which includes source clock source, sample rate and sample timing engine to generate signals.

For Fast generation, set maximum sample rate possible for the given "Sample Clock Source" input and assign smaller "Generation time" to generate. Min sample size is 2. For better resolution, configure the instrument to generate more samples eg. 1000 samples. Number of samples can be calculated from Generation time(s)/Sample rate(Fs).

    		Sample Clock Source

    Sample Clock Source specifies the source terminal of the Sample Clock.

    Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible sample clock sources.

    		Sample Rate (Hz)

    Sample Rate specifies the sampling rate in samples per channel per second. If you use an external source for the Sample Clock, set this input to the maximum expected rate of that clock.

    Maximum sample rate is 100KHz for TS-15110 module.

DAQ_Digital Edge Count Measurement.lvlib:DAQ_DECM Configure and Measure.vi

Configure, initiate and fetch no of digital events/edges detected from the channel configured.

NOTE: Initialize VI is recommended to create tasks instead of using tasks defined in NI-MAX directly. because initialize takes care of routing the output terminal of Timer task internally to reduce the need for additional PFI line output terminal.

Refer detailed help for more details on hardware timed vs software timed digital edge counting. And use the inputs accordingly.

Counter Settings

Counter Settings configures the active edge of the input signal to count, counting duration and wait type.

    		Active Edge[Active Edge]

    Active Edge specifies the raising/falling edge of the input signal to count

    		Duration (s)[Duration (s)]

    Duration (s) specifies the counting period. It applies for both software and hardware timed.

    Note: In software timed digital edge counting, Calling Measure Only reads the current counter value immediately without waiting for the specified time in Duration input. To wait internally, Use Configure and Measure option. Refer detailed help of this VI for more details.

    		Wait Type[Wait Type]

    Wait Type specifies whether to use a software wait or hardware window.

    Software Wait Type - Initiates the counting operation, waits for the duration specified and reads the current value of the counter. Use it for low frequency operations. If the Execution option is Measure Only, It will return the counter value immediately and do not wait for the specified duration. User has to introduce the required delay between Configure Only and Measure Only calls.

    Hardware Wait Type - Creates a measurement window using the Timer task. It will provide a precise edge counting for the specified duration. Use this for high frequency operations.

Execution Option

Execution Option specifies operations to execute.

Configure and Measure - Executes the complete VI which configures the instrument and performs the measurement

Configure Only - Sets the configuration to the instrument and Initiate but skips the fetch and measure. This is useful for external trigger usecases where the channel can be set to wait for the trigger and the execution can followed by that assets the trigger

Measure Only - Fetch the data captured in the instrument and performs the processing to return the measurements. Please note that Measure only cannot be repeated without preceding with the "Configure Only".

Note: In software timed digital edge counting, Calling Measure Only reads the current counter value immediately without waiting for the specified time in Duration input. To wait internally, Use Configure and Measure option.

Timer - Trigger Settings

Timer - Trigger Settings configures the Timer task to start the measurement on the configured trigger.

Select No Trigger in case of immediate start. Skip Digital Start Trigger Source and Digital Start Trigger Edge

Select Digital Start for triggered measurement . Required Fields: Digital Start Trigger Source and Digital Start Trigger Edge

    		Trigger Type

    The Trigger Type control selects which trigger type you wish to use. Depending on the selection, when you run the measurement, the task will configure the desired trigger type.

    Note that not all hardware supports triggering--refer to your device documentation for more info.

    		Digital Start Trigger Source[Digital Start Trigger Source]

    Digital Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

    Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

    		Digital Start Trigger Edge[Digital Start Trigger Edge]

    Edge specifies on which edge of the digital signal to start acquiring or generating samples.

error out

error out contains error information. If error in indicates that an error occurred before this VI or function ran, error out contains the same error information. Otherwise, error out describes the error status that this VI or function produces.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code

    code is the error or warning code. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source

    source identifies where and why an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

Edge Counts

Edge Counts returns the no of edges detected during the duration provided.

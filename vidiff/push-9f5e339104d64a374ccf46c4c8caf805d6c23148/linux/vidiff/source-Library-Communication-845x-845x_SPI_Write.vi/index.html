Communication.lvlib:845x_SPI Write.vi

NOTE: This example is taken from ni845x driver examples located at C:\Program Files (x86)\National Instruments\LabVIEW <version>\examples\ni845x\845xEx.llb. More such examples can be found in the same location.

This example shows a more generalized way to use the SPI basic API to write data. It allows the user to change the following parameters: page size, write delay, the endianness of the address bytes, and the number of bytes in an address.

The parameters will have the following effects:

Target Page Size (bytes): This places an additional constraint on the amount of bytes written. The smaller value will be used, and that number of bytes written.

Write Delay Between Pages (ms): This will force a mandatory delay after writing bytes to a device.

Data Address Width: This will allow the user to specify the EEPROM Data Address as either 1 or 2 bytes.

Data Address Endianness: This control will change the ordering of the bytes in the EEPROM Data Address, note that this only has an effect if there are 2 bytes in the address.

For connection information see the NI-845x Hardware and Software manual and the manual for your specific SPI device.

Chip Select

This indicates the chip select line that will be asserted during the SPI transfer. This line should be connected to your EEPROM.

Clock Rate (kHz)

This is the clock rate in Hz of each SPI transfer. The Atmel AT25080A supports transfers up to 10 Mhz for a 3.3V Vcc. The default of 1 Mhz is within this range. Please consult the data sheet for other transfers rate options.

Data to Write

Data to write specifies array of u8 data to be written.

Note: The AT25080 has a 32-byte page, so the maximum number of bytes to write is 32.

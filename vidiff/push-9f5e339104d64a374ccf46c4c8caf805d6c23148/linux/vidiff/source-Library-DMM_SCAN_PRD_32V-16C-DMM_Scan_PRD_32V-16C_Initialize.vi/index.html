DMM_Scan PXI RLY Driver 32V-16C.lvlib:DMM_Scan PRD 32V-16C Initialize.vi

Creates a new NI-DMM Scan driver session on each device specified in the Scan Resource Names control configured with the local powerline frequency. The devices use the powerline frequency value to select a timebase for setting the Aperture Time property in powerline cycles (PLCs). Change Powerline Frequency value to 60 Hz for North & South America.

A specific switch topology associated to a fixed hardware mapping channels defined by default for the random maximum 32 voltages and 16 currents configuration. Each channel number for current is linked to the same channel shunt number +16 starting from ch32. (ex. Current ch32 linked to Shunt ch48, ch33 linked to ch49...)

- "Close all Shunts" input is used to close all shunts relays from channels 48 to 63 (NI 2567) from the fixed Channels Topology Mapping, allowing to continuously powerthe DUT during all measurements.

Deselect "Close all shunts" optionally to open current shunts. For example, in the event a 2-Wire Resistance measurement function without any current through the DUT is desired.

- Relays Debounce Time (ms), defines the timing specifications for the external relays debounce time. Typical default Value is 5 ms, but needs to be adjusted with you specific choice of external relays.

The VI returns the switch max voltage and current characteristics from multiplexer and shunt relays, but only if the NI Multiplexer use embedded relays. The values will be 0 for external custom relays as for the NI 2567 Relay Driver only.

Switches Characteristics[Switches Characteristics]

Contains the Switches Characteristics in Max Voltage and Current.

Note: only if the NI Multiplexer use embedded relays. The values will be 0 for external custom relays as for the NI 2567 Relay Driver only.

    		MUX Characteristics[Mux Characteristics]

    Returns the maximum module switching characteristics.

    Switching voltage refers to the maximum signal voltage that the switch module can safely maintain.

    Switching current is the maximum rated current that can flow through the switch as it makes or breaks a contact. Switching active currents results in arcing that can damage the contacts of electromechanical relays.

    Max. DC Voltage (V) - Maximum DC voltage the module can support.

    Max. Switching DC Current (A) - Maximum DC Current the module can support when switching.

    Max. AC Voltage (V) - Maximum AC voltage the module can support.

    Max. Switching AC Current (A) - Maximum AC Current the module can support when switching.

Controls and Indicators

 Trigger Settings

Trigger Settings configures the power measurement to start aquisition on the configured trigger.

Select No Trigger in case of immediate aquisition. Skip Digital Start Trigger Source and Digital Start Trigger Edge

Select Digital Start for triggered aquisition. Required Fields: Digital Start Trigger Source and Digital Start Trigger Edge

    		Trigger Type

    The Trigger Type control selects which trigger type you wish to use. Depending on the selection, when you run the measurement, the task will configure the desired trigger type.

    Note that not all hardware supports triggering--refer to your device documentation for more info.

    		Digital Start Trigger Source[Digital Start Trigger Source]

    Digital Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

    Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

    		Digital Start Trigger Edge[Digital Start Trigger Edge]

    Edge specifies on which edge of the digital signal to start acquiring or generating samples.

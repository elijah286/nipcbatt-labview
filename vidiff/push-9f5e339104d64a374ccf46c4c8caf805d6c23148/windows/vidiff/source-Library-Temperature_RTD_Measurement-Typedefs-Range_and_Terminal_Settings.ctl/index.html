Range and Terminal Settings

Applicable for "Configure & Measure" & "Configure Only"

Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

    		Global Settings

    Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

      		Min Temp (deg C)

      Specifies the minimum temperature you expect to measure in degC.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Max Temp (deg C)

      Specifies the maximum temperature you expect to measure in degC.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		RTD Type

      RTD Type specifies the type of RTD connected to the channel.

      		Sensor Resistance at 0 deg C (Ohm)

      Sensor Resistance at 0 deg C specifies the resistance (in ohms).

      		Resistance Configuration

      Resistance Configuration specifies the number of wires to use for resistive measurements.

      		Current Excitation Source

      Current Excitation Source specifies the source of excitation.

      		Current Excitation (A)

      Current Excitation Value specifies in amperes the amount of excitation to supply to the sensor. Refer to the sensor documentation to determine this value.

      		ADC Timing Mode

      Specifies the ADC timing mode, controlling the tradeoff between speed and effective resolution. Some ADC timing modes provide increased powerline noise rejection. On devices that have an AI Convert clock, this setting affects both the maximum and default values for AIConv.Rate. Same ADC timing mode must be specified for all channels on a same device.

      Supported ADC modes are,

      Automatic - Uses the most appropriate supported timing mode based on the Sample Clock Rate.

      High Resolution - Increases resolution and noise rejection while decreasing conversion rate.

      High Speed - Increases conversion rate while decreasing resolution.

    		Specific Channel Settings

    Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

      		Channel Settings

      Channel Settings selects the type of channels on which the configuration must be applied. The settings can be applied to all analog input voltage channels or only on selective active channels.

        		Active Channels

        Specifies the physical channel to modify.

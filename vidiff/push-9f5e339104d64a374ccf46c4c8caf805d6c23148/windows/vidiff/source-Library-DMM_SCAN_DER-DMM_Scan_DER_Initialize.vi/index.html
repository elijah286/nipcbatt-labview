DMM_Scan DAQ Ext RLY.lvlib:DMM_Scan DER Initialize.vi

Creates a new NI-DMM Scan driver session on each device specified in the Scan Resource Names control configured with the local powerline frequency. The device uses the powerline frequency value to select a timebase for setting the Aperture Time property in powerline cycles (PLCs). Change Powerline Frequency value to 60 Hz for North & South America.

You must declare your custom hardware mapping and topology configuration first. Any DAQ device and port structure can be used including cDAQ relay driver modules and DIO TTL devices (with external amplification). You must declare your positions for the voltage type channels, then the list of current type channels followed by the N-shift position from the first current channel for the shunts. Later, all channels can be scanned randomly on each measurement type, in 2-wire (Differential) configuration. Dual Pole external relays (DPST) are needed for differential measurements attached to each DO line channel.

- "Close all Shunts" input is used to close all DAQ DO lines attached to shunt relay channels declared, allowing continuous power delivery to the DUT during all measurements. Deselect "Close all shunts" to open current shunts. For example, disable "Close all shunts" in the event of a 2-wire resistance measurement function without any current through the DUT.

- Relays Debounce Time (ms), defines the timing specifications for the external relays debounce time. Typical default Value is 5 ms, but needs to be adjusted for your specific choice of external relay.

The VI returns the Topology Mapping Output to easily check your Mapping declaration and save time to connect the appropriated channel lines of your device. It can help with maintenance and HW modifications.

For the Shunt channels, the link to the current channel number is returned.

    		DAQ Resource Physical Channels Names

    Physical Channel(s) specifies the names of the physical channels to use to create virtual channels. The DAQmx physical channel constant lists all physical channels on devices and modules installed in the system.

    To specify a range of physical channels, use a colon between two channel numbers or two physical channel names:

    DIO/port0/line0:4

    DIO/port0/line0:DIO/port0/line4

    You can specify channel ranges in reverse order:

    DIO/port0/line4:0

    Use commas to separate physical channel names and ranges in a list as follows:

    DIO/port0/line0, DIO/port0/line3:6

    If both physical and Global channels are provided, Global Channels will take precedence

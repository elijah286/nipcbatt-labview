DAQ_Temperature Thermocouple Measurement.lvlib:DAQ_TTC Meas Initialize.vi

Initialize analog input channels for Temperature Thermocouple and obtains a DAQmx task

Provide either Physical channel or Global Channel.

If both physical and Global channels are provided, Global Channels will take precedence

Note: For Physical Channel selection, CJC Source and CJC Channel must be configured.

Global Channels[Global Channels]

Global Channels specify Global channels configured in the NI Max to use it instead of initiating a new task using physical channels specified.

Physical Channels[Physical Channels]

Physical Channel(s) specifies the names of the physical channels to use to create virtual channels. The DAQmx physical channel constant lists all physical channels on devices and modules installed in the system.

To specify a range of physical channels, use a colon between two channel numbers or two physical channel names:

Dev1/ai0:4

Dev1/ai0:Dev1/ai4

You can specify channel ranges in reverse order:

Dev1/ai4:0

Use commas to separate physical channel names and ranges in a list as follows:

Dev1/ai0, Dev1/ai3:6

If both physical and Global channels are provided, Global Channels will take precedence

CJC Channel

CJC Channel specifies the channel that acquires the temperature of the thermocouple cold-junction if you set CJC Source to Channel. Uses a global channel or another virtual channel already in the task.

Note: If the channel is a temperature channel, NI-DAQmx acquires the temperature in the correct units. Other channel types, such as a resistance channel with a custom sensor, must use a custom scale to scale values to degrees Celsius.

CJC Source

CJC Source specifies the source of cold-junction compensation. The supported values are,

Channel - Uses the channel in CJC Channel Input.

Constant Value - Uses the cold-junction temperature in CJC Value input in TTC Meas Configure and Measure VI.

Internal - Uses the cold-junction compensation channel built into the terminal block. If no such channel is available, this VI returns an error.

DAQmx Task Out[DAQmx Task Out]

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.

Controls and Indicators

 Channel Settings

Configures power channel settings.

Applicable for "Configure & Measure" & "Configure Only"

Refer each control help for more details.

    		Voltage Setpoint(V)

    Voltage Setpoint specifies the constant output voltage, in volts.

    		Current Setpoint(A)

    Current Setpoint specifies the output current, in amperes.

    		Remote Sense

    Remote Sense specifies whether to use remote sense or local sense of the output voltage.

    Choose the appropriate one based on the connections to DUT.

    To learn more about Local Sense & Remote Sense, visit https://www.ni.com/docs/en-US/bundle/ts-15200-feature/page/GUID-8D7FB483-5BCF-4159-9DD0-747296A41625.html

    		Idle Output Behavior

    Idle Output Behavior specifies what should be the output after the end of power supply task.

    Disable output when Task stopped - There will be no output at the terminals since the output itself is disabled.

    Maintain Existing Value - The last output will be retained until next power supply task.

    		Enable Output?

    Specifies whether to enable or disable power module output.

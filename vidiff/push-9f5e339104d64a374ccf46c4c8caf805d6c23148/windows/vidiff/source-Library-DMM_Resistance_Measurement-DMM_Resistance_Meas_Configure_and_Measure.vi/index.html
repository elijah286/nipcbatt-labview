DMM_Resistance Measurement.lvlib:DMM_Resistance Meas Configure and Measure.vi

Configures an NI-DMM 2-wire or 4-wire resistance measurement on the resource provided by the DMM Handle In control according to the given Function, Execution, and Timing & Trigger settings, and then executes the measurement (by default).

Additionally users can choose to Configure Only without executing the measurement or Measure Only using the existing configuration.

Connector Pane

Front Panel

Controls and Indicators

 Execution Option

Execution Option specifies which operation to execute.

Configure and Measure - Will both configure the DMM according to the values provided on the front panel and will then execute the measurement.

Configure Only - Sets the configuration of the DMM but will not execute the measurement. This option can be useful to prepare a trigger and wait for a software or hardware event. This operation should be followed by a Measure Only.

Measure Only - Will skip configuration to perform a DMM read and formats the result into a string. Also will output the effective execution settings to an output cluster. Measure Only can be repeated, in this case the last configuration from the Configure Only operation will be used.

Measure Only - Will skip configuration to perform a DMM read and formats the result into a string. Also will output the execution settings to an output cluster.

DMM Handle In[DMM Handle In]

DMM Handle In identifies a particular NI-DMM session.

Function Settings

Range and Function specify which measurement will be made and the corresponding range of possible values to use for the measurement.

Resolution in Digits specifies the accuracy of the measurement in terms of the number of valid digits to include in the result.

    		Range and Function

    Specifies which measurement will be made and the corresponding range of possible values to use for the measurement.

    		Resolution in Digits[Resolution in Digits]

    Specifies the precision of the measurement in terms of the number of valid digits to include in the result.

Timing and Trigger Settings[Timing and Trigger Settings]

Aperture Time specifies the length of time during which the ADC is reading the signal.

Settle Time is the time required for a measurement system to stabilize to a specified accuracy limit.

AC Min Frequency specifies the minimum frequency the DMM uses for AC measurements.

Trigger Settings will be used to configure the source, delay, and slope of a hardware trigger if the user has an active trigger. Ensure the Enable Trigger? button is set to TRUE if using a trigger.

    		AC Min Frequency (Hz)[Aperture Time (s)]

    Only used for AC measurements, specifies the minimum expected frequency component of the input signal in hertz. This parameter will help to calculate the proper aperture time of the DMM.

    		Settle Time (s)

    Forces the value for the length of time during which the ADC is reading the signal. The DMM will automatically calculate this value. Modifying the default value from automatic (-1) will impact the measurement speed but can reduce the accuracy.

    		Trigger Settings

    Forces the value of the length of time required for a measurement system to stabilize to a specified accuracy limit. The DMM will automatically set this value. Modifying the default value from automatic (-1) will impact the measurement speed for a scan but can reduce the accuracy.

      		Trigger Delay (s)[Trigger Delay (sec)]

      Specifies the time the DMM waits after it has received a trigger before taking a measurement.

      		Enable Trigger?

      Set this button to TRUE if using a hardware trigger.

      		Trigger Source

      Selects the hardware trgger which will be used to trigger a measurement.

      		Slope[Slope]

      Specfies the direction of a signal that causes a trigger to occur.

error out

DMM Handle Out

DMM Handle Out outputs the DMM session used for the measurement.

DMM Execution Settings

This output cluster contains the values of all execution settings which were actually used by the driver during the measurement.

    		Absolute Resolution

    The smallest measurable increment that this DMM can detect.

    		Input Resistance (Ohm)

    The resistance presented by the DMM during the measurement.

    		Digits Resolution

    Indicates the number of digits displayed on the digital multimeter's readings.

    For example, for 5 digits, 00000 ~ 99999 can be displayed, but for 5 ½, this can be displayed when 000000 ~ 199999 are displayed. In other words, if ½ is used, it is used when the first digit is represented by only 0,1

    		Range

    The window of possible values that could be captured with this measurement.

    		Minimum Frequency (Hz)

    The minimum frequency component of the input signal parameter used during AC measurements.

    		Aperture Time (s)

    Value used during execution for the length of time for which the ADC was reading the signal.

    		Auto Range Value

    If auto range was used, displays the range that was selected by the automatic range finder and then used in the measurement.

    		Settle Time (s)

    Value used during execution by the full system needed to reach the specified accuracy limit.

    		Function

    Displays the type of measurement that was executed.

Measurement

Displays the final measurement captured. If the Out of Range indicator is lit, the measurement may be invalid due to an overrange condition.

    		Measured Value

    Displays the measurement as a numeric value for a limit comparison.

    		Out of Range

    If an overrange condition occurred during measurement this indicator will be lit and will hold a TRUE value.

    		Unit

    String value displaying the units of the measurement.

    		Measurement

    Contains the measurement captured by the DMM Read formatted into a single output string along with units.

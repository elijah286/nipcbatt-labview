DAQmx Tasks

DAQmx Tasks contains Counter and Timer tasks required for Digital Edge Count Measurement.

    		Counter DAQmx Task

    Counter DAQmx Task is a reference for the Counter Task used by Count Digital Events library.

    		Timer DAQmx Task

    Timer DAQmx Task is a reference for the Timer Task used by Count Digital Events library.

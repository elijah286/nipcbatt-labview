 Range and Terminal Settings

Range and Terminal Settings

Applicable for "Configure & Measure" & "Configure Only"

Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

    		Global Settings

    Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

      		Min. Temp (degC)[Min Temp (degC)]

      Specifies the minimum temperature you expect to measure in degC.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Max. Temp (degC)[Max Temp (degC)]

      specifies the maximum temperature you expect to measure in degC.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Vex Value (V) [Vex Value (V)]

      Specifies the voltage used for Excitation.

      Note: Library supports only external voltage excitation.

      		R1 (Ohm)[R1 (Ohm)]

      Specifies value of the dropping resistor in ohms when using voltage excitation.

      		Terminal Configuration

      Specifies the input terminal configuration for the channel.

      		Thermistor Parameters

      Specifies the parameters used to derive temperature measurements for NTC typed thermistor.

        		Type

        Selects the type of thermistor parameters to be considered for temperature measurement. The Options are -

        A B C - Specifies the Steinhart–Hart parameters for the specified thermistor. The parameters includes A, B and C constants.

        Beta - Specifies the B (Beta) parameters for the Thermistor.

        		ABC Parameters

        Specifies the Steinhart–Hart parameters for the specified thermistor. The parameters includes A, B and C constants which are used to derive Temperature measurements.

        Note: Refer the Thermistor Datasheet to determine these parameter values.

          		A

          A is the A constant for the Steinhart–Hart equation.

          		B

          B is the B constant for the Steinhart–Hart equation.

          		C

          C is the C constant for the Steinhart–Hart equation.

        		Beta Parameters

        Specifies the B (Beta) parameters for the Thermistor which are used to derive Temperature measurements.

        Note: Refer the Thermistor Datasheet to determine these parameter values.

          		Beta Value (K)

          Specifies the Beta Value in Kelvin for the specified NTC Thermistor.

          		R0 (Ohm)

          Specifies the Nominal Resistance (R0) in Ohms for the specified NTC Thermistor measured at 25 degC.

    		Specific Channel Settings

    Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

      		Channel Settings

      Channel Settings selects the type of channels on which the configuration must be applied. The settings can be applied to all analog input temperature measurement channels or only on selective active channels.

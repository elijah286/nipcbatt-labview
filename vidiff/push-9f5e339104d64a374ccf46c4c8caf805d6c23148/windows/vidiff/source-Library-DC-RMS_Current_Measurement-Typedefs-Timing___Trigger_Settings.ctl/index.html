 Timing & Trigger Settings

Timing and Trigger Settings sets the timing and trigger settings for power supply task.

Applicable for "Configure & Measure" & "Configure Only"

Refer help of each settings to configure them appropriately.

    		Timing Settings

    Timing Settings sets the timing details for DC Current measurements which includes source clock source, sample rate, number of samples and sample timing engine to measure DC current measurements

    For Fast measurements, set maximum sample rate possible for the given "Sample Clock Source" input and assign smaller "Number of Samples" to capture. Min sample size is 2. For better resolution, configure the instrument to read more samples eg. 1000 samples.

      		Sample Clock Source

      Sample Clock Source specifies the source terminal of the Sample Clock.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible sample clock sources.

      		Sample Rate (Hz)

      Sample Rate specifies the sampling rate in samples per channel per second. If you use an external source for the Sample Clock, set this input to the maximum expected rate of that clock.

      		Number of Samples

      Number of Samples specifies the number of samples to read.

      For Fast measurements, assign smaller "Number of Samples" to capture. Min sample size is 2. For better resolution, configure the instrument to read more samples eg. 1000

      		Sample Timing Engine

      Sample Timing Engine specifies which timing engine to use for the task. Choose Auto to let the instrument use the default one.

    		Trigger Settings

    Trigger Settings configures the power measurement to start acquisition on the configured trigger.

    Applicable for "Configure & Measure" & "Configure Only"

    Select No Trigger in case of immediate acquisition. Skip Digital Start Trigger Source and Digital Start Trigger Edge

    Select Digital Start for triggered acquisition. Required Fields: Digital Start Trigger Source and Digital Start Trigger Edge

      		Trigger Type[Trigger Type]

      The Trigger Type control selects which trigger type you wish to use. Depending on the selection, when you run the measurement, the task will configure the desired trigger type.

      Note that not all hardware supports triggering--refer to your device documentation for more info.

      		Digital Start Trigger Source[Digital Start Trigger Source]

      Digital Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

      		Digital Start Trigger Edge[Digital Start Trigger Edge]

      Edge specifies on which edge of the digital signal to start acquiring or generating samples.

DAQ_Digital Edge Count Measurement.lvlib:DAQ_DECM Initialize.vi

Initialize Counter task and Timer task for digital edge count measurement task.

Two tasks are used for Digital Edge Count Measurement. Counter task is used for edge counting and Timer task is used to control precise measurement window for edge counting by generating a single pulse of required measurement time and it is used for hardware timed wait type. This generated pulse will be internally used by Counter task. No external physical connections are required.

NOTE: Leave Counter - Timer input empty for software timed wait type.

Refer detailed help for more details on hardware timed vs software timed wait types.

Counter - Timer

Counter - Timer specifies the counter resource needed for Timer task.

Timer task is used to control precise measurement window for edge counting by generating a single pulse of required measurement time and it is used for hardware timed wait type. This generated pulse will be internally used by Counter task. No external physical connections are required.

Note: Skip this input for software timed operations. Refer detailed help of this VI for more details on hardware timed vs software timed digital edge counting.

Counter - Edge Counting

Counter - Edge Counting specifies the counter resource needed for Edge counting operation.

Input Terminal

Input Terminal specifies the input terminal on which to look for digital events / edges.

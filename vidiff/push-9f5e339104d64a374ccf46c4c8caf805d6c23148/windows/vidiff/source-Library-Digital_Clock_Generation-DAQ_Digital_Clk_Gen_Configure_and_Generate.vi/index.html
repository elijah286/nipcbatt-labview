 Digital Clock Settings

Digital Clock Settings configures the Frequency, Duty cycle and Generation time to generate a digital clock signal

    		Frequency (Hz)

    Frequency specifies at what frequency to generate clock.

    		Duty Cycle(%)

    duty cycle is the width of the pulse divided by the pulse period. NI-DAQmx uses this ratio combined with frequency to determine pulse width and the interval between pulses.

    		Generation Time (s)[Generation Time (s)]

    Generation Time (s) is the time for the generation of the Digital clock signal

    It is recommended to select the generation time (s) as an integral multiple of the time period (1/Frequency (Hz)) such that complete cycles are generated.

error out[error out]

error out contains error information. If error in indicates that an error occurred before this VI or function ran, error out contains the same error information. Otherwise, error out describes the error status that this VI or function produces.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code[code]

    code is the error or warning code. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source[source]

    source identifies where and why an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

DAQmx Task Out[DAQmx Task Out]

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.

Actual Clock Settings

Actual Clock Settings returns the actual frequency, dutycycle and Generation time of generated digital signal from instrument

    		[Frequency (Hz)]

    Frequency (Hz) returns the actual frequency of the clock to be generated

    		[Duty Cycle (%)]

    Duty Cycle (%) returns the actual duty cycle of the clock to be generated

    		[Generation Time (s)]

    Generation Time (s) returns the total generation time of digital signal in seconds which is based on the coerced value of the sample clock rate and the number of pulses.

    Generation time = Number Of Pulses*Time period

Timebase Frequency (Hz)

Timebase Frequency (Hz) specifies the frequency of Counter timebase in Hz. Timebase is set based on the input configurations to support required frequency.

Supported frequency range to generate clock depends on the available Timebase.

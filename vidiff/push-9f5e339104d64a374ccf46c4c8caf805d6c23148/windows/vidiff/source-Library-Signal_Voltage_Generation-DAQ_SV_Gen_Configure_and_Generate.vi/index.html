Configure, initiate and generate signal voltage waveforms from the channels configured.

 DAQmx Task In[DAQmx Task In]

DAQmx Task In is the name of the task or a list of virtual channels to which the operation applies. If you provide a list of virtual channels, NI-DAQmx creates a task automatically.

error in[error in]

error in can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code[code]

    code is the error or warning code.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source[source]

    source describes the origin of the error or warning.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

Range and Terminal Settings[Range and Terminal Settings]

Range and Terminal Settings configures the voltage supply range settings for all analog output voltage channels.

    		Min Voltage (V)[Min Voltage (V)]

    Min Voltage specifies the minimum value you expect to generate in output channel.

    		Max Voltage (V)[Max Voltage (V)]

    Max Voltage specifies the maximum value you expect to generate in output channel.

Signal Generation Settings[Signal Generation Settings]

Signal Generation Settings contains the required configuration for signal generation. The configuration can generate both single tone and multi tone signals for a defined generation time(s). The Single tone signals supports both sine and square waves.

    		Generation Type[Generation Type]

    Generation Type specifies the type of tone to generate by DAQmx analog output

    		Generation Time (s)[Generation Time (s)]

    Generation Time (s) is the time for the generation of the single/multi-tone waveform.

    It is recommended to select the generation time (s) as an integral multiple of the time period (1/Frequence (Hz)) such that complete cycles of each tone are generated.

    For Multitone Generation, it is required that the generation time (s) is an integral multiple of the time period (1/Frequence (Hz)) of all the tones

    		Voltage Offset (v)[Voltage Offset (v)]

    Voltage Offset (s) represents the offset voltage to apply on the ouput generated waveform in the analog output channels.

    		Single Tone Settings[Single Tone Settings]

    Digital Start Trigger Setting configures the analog input measurement to start acquisition on digital edge trigger from source terminal

      		Waveform Type[Waveform Type]

      Waveform Type specifies the type of waveform to generate in a single tone method. It supports sine wave and square wave generation.

      		Frequency (Hz)[Frequency (Hz)]

      Frequency (Hz) represents the frequency in Hertz for the generated waveform.

      		Amplitude (V)[Amplitude (V)]

      Amplitude (V) represents the amplitude in Volts for the generated waveform.

      		Duty Cycle (%)[Duty Cycle (%)]

      Duty Cycle (%) represents the duty cycle in percentage(%) units for the generated waveform. This option is only applicable for Square waveform generation.

    		Multi Tone Settings[Multi Tone Settings]

    Multi Tone Settings allows to enter multiple tone settings which are integrated into to a single generation tone. The settings includes Frequency(Hz) and Amplitude(V) for each tone.

    Multi tone settings are applicable only for sine wave.

    It is recommended to select the Frequency(Hz) of each tone to be a integral multiple of (1/Generation Time(s)). So that complete cycle of each tone is present in the generated tone.

    In other words, each tone Frequency(Hz) should be a integral multiple of Fs/N. Where Fs is the "Sampling Rate" and "N" is the number of samples.

    The VI might throw an error if any frequency does not follow the above rule.

      		Tone Settings

      Tone Settings configures the requried settings to generate a tone which includes frequency (Hz) and amplitude (V)

        		Frequency (Hz)

        Frequency (Hz) represents generated waveform frequency in Hertz

        		Amplitude (V)

        Amplitude (V) represents the generated waveform amplitude in Voltage.

Timing & Trigger Settings[Timing & Trigger Settings]

Timing and Trigger Settings sets the timing and trigger settings for the task.

    		Trigger Settings

    Digital Start Trigger Setting configures the task to start acquisition/generation on digital edge trigger from source terminal

    Select No Trigger in case of immediate generation. Skip Digital Start Trigger Source and Digital Start Trigger Edge

    Select Digital Start for triggered generation. Required Fields: Digital Start Trigger Source and Digital Start Trigger Edge

      		Trigger Type[Trigger Type]

      The Trigger Type control selects which trigger type you wish to use. Depending on the selection, when you run the measurement, the task will configure the desired trigger type.

      Note that not all hardware supports triggering--refer to your device documentation for more info.

      		Digital Start Trigger Source[Digital Start Trigger Source]

      Digital Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

      		Digital Start Trigger Edge[Digital Start Trigger Edge]

      Edge specifies on which edge of the digital signal to start acquiring or generating samples.

    		Timing Settings

    Timing Settings sets the timing details for signal voltage generation which includes source clock source, sample rate and sample timing engine to generate signals.

    For Fast generation, set maximum sample rate possible for the given "Sample Clock Source" input and assign smaller "Generation time" to generate. Min sample size is 2. For better resolution, configure the instrument to generate more samples eg. 1000 samples. Number of samples can be calculated from Generation time(s)/Sample rate(Fs).

      		Sample Clock Source

      Sample Clock Source specifies the source terminal of the Sample Clock.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible sample clock sources.

      		Sample Rate (Hz)

      Sample Rate specifies the sampling rate in samples per channel per second. If you use an external source for the Sample Clock, set this input to the maximum expected rate of that clock.

error out[error out]

error out contains error information. If error in indicates that an error occurred before this VI or function ran, error out contains the same error information. Otherwise, error out describes the error status that this VI or function produces.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code[code]

    code is the error or warning code. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source[source]

    source identifies where and why an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

DAQmx Task Out[DAQmx Task Out]

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.

Generated Voltage Waveforms[Generated Voltage Waveforms]

Generated Voltage Waveforms displays the generated voltage waveforms by the signal voltage generation VI.

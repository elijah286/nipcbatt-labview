 Signal Generation Settings[Signal Generation Settings]

Signal Generation Settings contains the required configuration for signal generation. The configuration can generate both single tone and multi tone signals for a defined generation time(s). The Single tone signals supports both sine and square waves.

    		Generation Type[Generation Type]

    Generation Type specifies the type of tone to generate by DAQmx analog output

    		Generation Time (s)[Generation Time (s)]

    Generation Time (s) is the time for the generation of the single/multi-tone waveform.

    It is recommended to select the generation time (s) as an integral multiple of the time period (1/Frequence (Hz)) such that complete cycles of each tone are generated.

    For Multitone Generation, it is required that the generation time (s) is an integral multiple of the time period (1/Frequence (Hz)) of all the tones

    		Voltage Offset (v)[Voltage Offset (v)]

    Voltage Offset (s) represents the offset voltage to apply on the ouput generated waveform in the analog output channels.

    		Single Tone Settings[Single Tone Settings]

    Digital Start Trigger Setting configures the analog input measurement to start acquisition on digital edge trigger from source terminal

      		Waveform Type

      Waveform Type specifies the type of waveform to generate in a single tone method. It supports sine wave and square wave generation.

      		Frequency (Hz)

      Frequency (Hz) represents the frequency in Hertz for the generated waveform.

      		Amplitude (V)

      Amplitude (V) represents the amplitude in Volts for the generated waveform.

      		Duty Cycle (%)

      Duty Cycle (%) represents the duty cycle in percentage(%) units for the generated waveform. This option is only applicable for Square waveform generation.

    		Multi Tone Settings[Multi Tone Settings]

    Multi Tone Settings allows to enter multiple tone settings which are integrated into to a single generation tone. The settings includes Frequency(Hz) and Amplitude(V) for each tone.

    Multi tone settings are applicable only for sine wave.

    It is recommended to select the Frequency(Hz) of each tone to be a integral multiple of (1/Generation Time(s)). So that complete cycle of each tone is present in the generated tone.

    In other words, each tone Frequency(Hz) should be a integral multiple of Fs/N. Where Fs is the "Sampling Rate" and "N" is the number of samples.

    The VI might throw an error if any frequency does not follow the above rule.

      		Tone Settings

      Tone Settings configures the requried settings to generate a tone which includes frequency (Hz) and amplitude (V)

        		Frequency (Hz)

        Frequency (Hz) represents generated waveform frequency in Hertz

        		Amplitude (V)

        Amplitude (V) represents the generated waveform amplitude in Voltage.

Range and Terminal Settings[Range and Terminal Settings]

Range and Terminal Settings

Applicable for "Configure & Measure" & "Configure Only"

Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

    		Global Settings

    Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

      		Min Range(V)

      Min Voltage specifies the minimum value you expect to measure.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Max Range(V)

      Max Voltage specifies the maximum value you expect to measure.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Terminal Configuration

      Terminal Configuration specifies the input terminal configuration for the channel.

    		Specific Channel Settings

    Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

      		Channel Settings

      Channel Settings selects the type of channels on which the configuration must be applied. The settings can be applied to all analog input voltage channels or only on selective active channels.

        		Active Channels

        Specifies the physical channel to modify.

        		Min Range

        Min Voltage specifies the minimum value you expect to measure.

        This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

        		Max Range

        Max Voltage specifies the maximum value you expect to measure.

        This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

        		Terminal Configuration

        Terminal Configuration specifies the input terminal configuration for the channel.

error out[error out]

error out passes error or warning information out of a VI to be used by other VIs.

Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code[code]

    code is the error or warning code.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source[source]

    source describes the origin of the error or warning.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

Generated Voltage Waveforms[Generated Voltage Waveforms]

Generated Voltage Waveforms displays the generated voltage waveforms by the signal voltage generation VI.

Voltage Waveforms[Measured Voltage Waveforms]

Voltage Waveforms displays the most recent acquired data. If the output is disabled, the data read will be NaN, and the graph will be blank for those points.

Time Domain Measurements[Time Domain Measurements]

Displays the time domain measurements results.

NOTE: Captured waveform should contain more than one cycle to calculate Voltage Waveform Period (s) and Voltage Waveform duty cycle (%).

    		Mean DC Voltage (V)[Mean DC Voltage (V)]

    Mean DC value is the measured DC value in volts if the signal is in volts.

      		Mean DC Voltage (V)

      DC value is the measured DC value in volts if the signal is in volts.

    		Vpp Amplitude(V)[Vpp Amplitude(V)]

    Vpp Amplitude represents the peak to peak amplitude observed in the capture waveforms

      		Vpp Amplitude(V)

      amplitude is the difference between high state level and low state level.

    		Voltage Frequency(Hz)[Voltage Frequency(Hz)]

    Detected frequency is the frequency of the detected single tone in Hz.

      		Voltage frequency(Hz)

      detected frequency is the frequency of the detected single tone in Hz.

    		Voltage Waveform Period (s)[Voltage Waveform Period (s)]

    Voltage Waveform Period returns the time between adjacent mid ref level crossings in the same direction in seconds.

      		Voltage waveform period (s)

      period returns the time between adjacent mid ref level crossings in the same direction in seconds.

    		Voltage Waveform duty cycle (%)[Voltage Waveform duty cycle (%)]

    Duty cycle observed in the captured waveform in a fraction of a period.

      		Voltage Waveform duty cycle (%)

      duty cycle is a fraction of a period.

DMM_Scan DAQ Ext RLY.lvlib:Wait For Debounce External Relays.vi

Debounce wait time based on the external relay timing specifications. Typical default value is 5 ms, but needs to be adjusted with your specific choice of external relays.

Incorrect values (too short) will affect the accuracy of the measurements.

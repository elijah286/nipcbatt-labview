 Counter Settings

Counter Settings configures the active edge of the input signal to count, counting duration and wait type.

    		Active Edge[Active Edge]

    Active Edge specifies the raising/falling edge of the input signal to count

    		Duration (s)[Duration (s)]

    Duration (s) specifies the counting period. It applies for both software and hardware timed.

    Note: In software timed digital edge counting, Calling Measure Only reads the current counter value immediately without waiting for the specified time in Duration input. To wait internally, Use Configure and Measure option. Refer detailed help of this VI for more details.

    		Wait Type[Wait Type]

    Wait Type specifies whether to use a software wait or hardware window.

    Software Wait Type - Initiates the counting operation, waits for the duration specified and reads the current value of the counter. Use it for low frequency operations. If the Execution option is Measure Only, It will return the counter value immeditely and do not wait for the specified duration. User has to introduce the required delay between Configure Only and Measure Only calls.

    Hardware Wait Type - Creates a measurement window using the Timer task. It will provide a precise edge counting for the specifed duration. Use this for high frequency operations.

Timer - Trigger Settings

Timer - Trigger Settings configures the Timer task to start the measurement on the configured trigger.

Select No Trigger in case of immediate start. Skip Digital Start Trigger Source and Digital Start Trigger Edge

Select Digital Start for triggered measurement . Required Fields: Digital Start Trigger Source and Digital Start Trigger Edge

    		Trigger Type

    The Trigger Type control selects which trigger type you wish to use. Depending on the selection, when you run the measurement, the task will configure the desired trigger type.

    Note that not all hardware supports triggering--refer to your device documentation for more info.

    		Digital Start Trigger Source[Digital Start Trigger Source]

    Digital Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

    Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

    		Digital Start Trigger Edge[Digital Start Trigger Edge]

    Edge specifies on which edge of the digital signal to start acquiring or generating samples.

Digital Clock Settings

Digital Clock Settings configures the Frequency, Duty cycle and Generation time to generate a digital clock signal

    		Frequency (Hz)

    Frequency specifies at what frequency to generate clock.

    		Duty Cycle(%)

    duty cycle is the width of the pulse divided by the pulse period. NI-DAQmx uses this ratio combined with frequency to determine pulse width and the interval between pulses.

    		Generation Time (s)[Generation Time (s)]

    Generation Time (s) is the time for the generation of the Digital clock signal

    It is recommended to select the generation time (s) as an integral multiple of the time period (1/Frequency (Hz)) such that complete cycles are generated.

error out

error out passes error or warning information out of a VI to be used by other VIs.

Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code

    code is the error or warning code.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source

    source describes the origin of the error or warning.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

Edge Counts

Edge Counts returns the no of edges detected during the duration provided.

Actual Clock Settings

Actual Clock Settings returns the actual frequency, dutycycle and Generation time of generated digital signal from instrument

    		[Frequency (Hz)]

    Frequency (Hz) returns the actual frequency of the clock to be generated

    		[Duty Cycle (%)]

    Duty Cycle (%) returns the actual duty cycle of the clock to be generated

    		[Generation Time (s)]

    Generation Time (s) returns the total generation time of digital signal in seconds which is based on the coerced value of the sample clock rate and the number of pulses.

    Generation time = Number Of Pulses*Time period

 Path Status[Path Status]

Indicates whether a switch path is valid before applying a Connect/Disconnect action. Possible values include:

Path Available (1) - Indicates that the driver can create the path at this time.

Path Exists (2) - Indicates that the explicit path between the channels already exists.

Path Unsupported (3) - Indicates that the instrument is not capable of creating a path between the two channels.

Resource In Use (4) - Indicates that although the path is valid, the driver cannot create the path at this moment because the switch module is currently using one or more of the required channels to create another path. You must destroy the other path before creating this one.

Source Conflict (5) - Indicates that the instrument cannot create a path because both channels are connected to a different source channel.

Channel Not Available (6) - Indicates that the driver cannot create a path between the two channels because one of the channels is a configuration channel and thus unavailable for external connections.

Other (0) - Indicates another issue like an unknown channel or a previous error input. In this case check the error status message.

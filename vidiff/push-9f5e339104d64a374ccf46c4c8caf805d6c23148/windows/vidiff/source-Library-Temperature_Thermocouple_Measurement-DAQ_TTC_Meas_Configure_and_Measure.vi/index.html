Execution Option

Execution Option specifies operations to execute.

Configure and Measure - Executes the complete

VI which configures the instrument and performs the

measurement

Configure Only - Sets the configuration to the

instrument and Initiate but skips the fetch and measure. This

is useful for external trigger usecases where the channel can

be set to wait for the trigger and the execution can followed

by that assets the trigger

Measure Only - Fetch the data captured in the

instrument and performs the processing to return the

measurements. Please note that Measure only cannot be

repeated without preceding with the "Configure Only"

Timing and Trigger Settings

Timing and Trigger Settings sets the timing and trigger settings for analog input task.

Applicable for "Configure & Measure" & "Configure Only"

Refer help of each settings to configure them appropriately.

    		Timing Settings

    Timing Settings sets the timing settings for analog input task which includes source clock source, sample rate, number of samples and sample timing engine.

    s

    Applicable for "Configure & Measure" & "Configure Only"

    Refer below scenario that will help in selecting appropriate values for Sample Rate and Number of Samples.

    Total acquisition time is based on sample rate and no of samples given.

    Acquisition time = Number Of Samples/Sample rate

    For Fast measurements, set maximum sample rate possible for the given "Sample Clock Source" input and assign smaller "Number of Samples" to capture. Minimum value for Number of Samples is 2

    For Precise measurements, assign higher "Number of Samples" to capture. Eg. 1000

    Refer help for each controls for more details.

      		Sample Clock Source

      Sample Clock Source specifies the source terminal of the Sample Clock.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible sample clock sources.

      		Sample Rate(Hz)

      Sample Rate specifies the sampling rate in samples per channel per second. If you use an external source for the Sample Clock, set this input to the maximum expected rate of that clock.

      Note: Maximum aggregate sampling rate for cDAQ Temperature Input modules like NI 9211 is 14 S/s. Setting values more than that will generate an error.

      		Number of Samples

      Number of Samples specifies the number of samples to read.

      For Fast measurements, assign smaller "Number of Samples" to capture. Min sample size is 2. For better resolution, configure the instrument to read more samples eg. 1000.

      Note: Maximum aggregate sampling rate for cDAQ Temperature input modules like NI 9211 is 14 S/s. Setting more samples to read will increase the measurement acquisition time.

      		Sample Timing Engine

      Sample Timing Engine specifies which timing engine to use for the task. Choose Auto to let the instrument use the default one.

    		Trigger Settings

    Trigger Settings configures the power measurement to start acquisition on the configured trigger.

    Select No Trigger in case of immediate acquisition. Skip Digital Start Trigger Source and Digital Start Trigger Edge

    Select Digital Start for triggered acquisition. Required Fields: Digital Start Trigger Source and Digital Start Trigger Edge

      		Trigger Type

      The Trigger Type control selects which trigger type you wish to use. Depending on the selection, when you run the measurement, the task will configure the desired trigger type.

      Note that not all hardware supports triggering--refer to your device documentation for more info.

      		Digital Start Trigger Source[Digital Start Trigger Source]

      Digital Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

      		Digital Start Trigger Edge[Digital Start Trigger Edge]

      Edge specifies on which edge of the digital signal to start acquiring or generating samples.

Range and Terminal Settings

Range and Terminal Settings

Applicable for "Configure & Measure" & "Configure Only"

Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

    		Global Settings

    Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

      		Min Temp (deg C)

      Specifies the minimum temperature you expect to measure in degC.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Max Temp (deg C)

      pecifies the maximum temperature you expect to measure in degC.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Thermocouple Type

      Thermocouple Type specifies the type of thermocouple connected to the channel. Thermocouple types differ in composition and measurement range.

      Refer the Thermocouple datasheet to determine its type.

      		CJC Temp (deg C)

      CJC value specifies in units the temperature of the cold junction if you set cjc source to Constant Value.

      		Autozero[Enable Autozero]

      Enable Autozero determines whether Auto Zero is enabled. If Enabled, NI-DAQ device shorts the input channel to ground and subtracts the obtained measurement from all subsequent samples.

      Refer the targeted NI Device documentation to check if Autozero feature is supported.

      		Auto Zero Mode[Auto Zero Mode]

      Auto Zero Mode specifies how often to measure ground. NI-DAQmx subtracts the measured ground voltage from every sample. The supported values are,

      Every Sample - Perform an auto zero at every sample of the acquisition.

      None - Do not perform an autozero.

      Once - Perform an auto zero at the beginning of the acquisition. This auto zero task might not run if you have used DAQmx Control Task previously in your task.

    		Specific Channel Settings

    Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

      		Channel Settings

      Channel Settings selects the type of channels on which the configuration must be applied. The settings can be applied to all analog input voltage channels or only on selective active channels.

        		Physical Channel Name

        Specifies the physical channel to modify.

        		Thermocouple Type[Thermocouple Type]

        Thermocouple Type specifies the type of thermocouple connected to the channel. Thermocouple types differ in composition and measurement range.

Acquisition Time (s)[Acquisition Time (s)]

Acquisition Time Period returns the total acquisition time by the instrument in seconds which is based on the coerced value of the sample clock rate and the number of samples.

Acquisition time = Number Of Samples/Sample rate

For Fast measurements, set maximum sample rate possible for the given "Sample Clock Source" input and assign smaller "Number of Samples" to capture. Minimum value for Number of Samples is 2

For Precise measurements, assign higher "Number of Samples" to capture. Eg. 1000

NOTE: Acquisition Time of Measurement is updated only during Configure Only and Configure & Measure calls, not in Measure Only call.

error out[error out]

error out contains error information. If error in indicates that an error occurred before this VI or function ran, error out contains the same error information. Otherwise, error out describes the error status that this VI or function produces.

    		status[status]

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code[code]

    code is the error or warning code. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source[source]

    source identifies where and why an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

DAQmx Task Out[DAQmx Task Out]

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.

Temperature Waveforms[Temperature Waveforms]

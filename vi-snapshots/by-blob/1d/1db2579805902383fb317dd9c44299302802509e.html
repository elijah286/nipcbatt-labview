DAQ_Digital PWM Measurement.lvlib:DAQ_Dig PWM Meas Configure and Measure.vi

Configure, initiate, and fetch digital PWM measurements from the channels configured.

Note: The default timeout for PWM Measurements is 10 seconds. If the time elapses before the requested cycles are captured, the VI returns a error. Users can manually edit this timeout based on the captured PWM signal time period.

Execution Option

Execution Option specifies operations to execute.

Configure and Measure - Executes the complete VI which configures the instrument and performs the measurement.

Configure Only - Sets the configuration to the instrument and Initiate but skips the fetch and measure. This is used to set the channel to wait for the detection of first rising edge before the input signal starts.

Measure Only - Fetch the data captured in the instrument and performs the processing to return the measurements. Please note that Measure only cannot be repeated without preceding with the "Configure Only"

Execution options can be used to capture the entire signal by setting the channel to wait for the first Rising edge using Configure Only mode before the generation of input signal. After capturing the cycles, Measure Only mode can be used to read the measured data.

Cycles to capture

Cycles to capture specifies the number of PWM cycles to capture which are averaged to derive Digital PWM Measurements

Note: Low time for a single pulse cannot be determined as it might not have a clear ending (Rising edge). So, Minimum cycles required for PWM Measurement is 2.

Digital PWM Measurements

Digital PWM Measurements specifies the derived PWM measurements from the captured digital waveform. The PWM measurements include High Time(s), Low Time(s), Duty Cycle(%) and Frequency(Hz).

    		High Time (s)

    High Time (s) specifies the averaged time (in seconds) during which a pulse remains High in the PWM waveform.

    		Low Time (s)

    Low Time (s) specifies the averaged time (in seconds) during which a pulse remains Low in the PWM waveform.

    		Duty Cycle (%)

    Duty Cycle (%) specifies the averaged duty cycle (in percentage) measured in the PWM Waveform.

    Duty Cycle (%) = (High Time/Pulse Period)*100

    		Frequency (Hz)

    Frequency (Hz) specifies the frequency of the captured digital PWM waveform.

    Frequency (Hz) = 1 / Pulse Period (s)

DAQmx Task Out

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.

error out

error out contains error information. If error in indicates that an error occurred before this VI or function ran, error out contains the same error information. Otherwise, error out describes the error status that this VI or function produces.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code

    code is the error or warning code. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source

    source identifies where and why an error occurred. The source string includes the name of the VI that produced the error, what inputs are in error, and how to eliminate the error.

Actual Cycles Captured

Actual Cycles Captured specifies the actual no. of cycles captured during the measurement.

NOTE: It is updated only during the Measure Only and Configure & Measure calls, not in Configure Only call.

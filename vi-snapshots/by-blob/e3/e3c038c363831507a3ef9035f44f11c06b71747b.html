DAQ_Digital Frequency Measurement.lvlib:DAQ_Dig Freq Meas Initialize.vi

Initialize Counter Input task for digital frequency measurement.

Provide either Physical channel or Global channel for counters to use.

If both physical and global channels are provided, Global Channels will take precedence

Note: Multiple counters cannot be initialized in the same task for input operations. Use separate task for each counter.

Connector Pane

Front Panel

Controls and Indicators

 Physical Channel (counter)

Physical Channel (counter) specifies the name of the counter to use to create the virtual channel. The DAQmx physical channel constant lists all physical channels, including counters, for devices installed in the system.

Note: Counter 0 is always paired with Counter 1. Counter 2 is always paired with Counter 3 for the measurement method used here (Large Range (2 Counters)). Paired counters cannot be used in different tasks.

Global Channel (counter)

Global Channel specify Global channels configured in the NI Max to use it instead of initiating a new task using physical channels specified.

Note I : Global channel(s) should be declared as Counter Input - Frequency. Global channel settings will be overwritten by Configure and Measure VI.

Note II : Counter 0 is always paired with Counter 1. Counter 2 is always paired with Counter 3 for the measurement method used here (Large Range (2 Counters)). Paired counters cannot be used in different tasks.

Input Terminal

Input Terminal specifies the terminal on which the signal is to be measured.

Note: Refer default terminal for each counter in the detailed help. User can configure different PFI lines as well.

DAQmx Task Out

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.

DMM_Scan PXI Mux PXI Shunt 16V-15C.lvlib:DMM_Scan PMPS 16V-15C Initialize.vi

Creates a new NI-DMM Scan driver session on each device specified in the Scan Resource Names control configured with the local powerline frequency. The devices use the powerline frequency value to select a timebase for setting the Aperture Time property in powerline cycles (PLCs). Change the Powerline Frequency value to 60 Hz for North & South America.

A specific switch topology associated to a fixed channel mapping is defined by default for the random 16 voltage and 15 current configuration. Each channel number for current is linked to the same channel shunt number. (ex. Current ch16 = Shunt ch16)

The "Close all Shunts" input control is used to close all relays from channels 16 to 30 (NI 2568) in a fixed channel topology mapping, allowing continuous power to the DUT during all measurements. Deselect "Close all shunts" to open current shunts. For example, deselect "Close all shunts" in the instance of a 2-Wire Resistance measurement function without any current through the DUT.

The VI returns the max voltage and current characteristics from each multiplexer and shunt relay.

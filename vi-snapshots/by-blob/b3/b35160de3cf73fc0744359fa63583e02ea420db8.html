 Signal Generation Settings

Signal Generation Settings contains the required configuration for signal generation. The configuration can generate both single tone and multi tone signals for a defined generation time(s). The Single tone signals supports both sine and square waves.

    		Generation Type[Generation Type]

    Generation Type specifies the type of tone to generate by DAQmx analog output

    		Generation Time (s)

    Generation Time (s) is the time for the generation of the single/multi-tone waveform.

    It is recommended to select the generation time (s) as an integral multiple of the time period (1/Frequence (Hz)) such that complete cycles of each tone are generated.

    For Multitone Generation, it is required that the generation time (s) is an integral multiple of the time period (1/Frequence (Hz)) of all the tones

    		Voltage Offset (v)

    Voltage Offset (s) represents the offset voltage to apply on the ouput generated waveform in the analog output channels.

    		Single Tone Settings

    Digital Start Trigger Setting configures the analog input measurement to start acquisition on digital edge trigger from source terminal

      		Waveform Type

      Waveform Type specifies the type of waveform to generate in a single tone method. It supports sine wave and square wave generation.

      		Frequency (Hz)

      Frequency (Hz) represents the frequency in Hertz for the generated waveform.

      		Amplitude (V)

      Amplitude (V) represents the amplitude in Volts for the generated waveform.

      		Duty Cycle (%)

      Duty Cycle (%) represents the duty cycle in percentage(%) units for the generated waveform. This option is only applicable for Square waveform generation.

    		Multi Tone Settings

    Multi Tone Settings allows to enter multiple tone settings which are integrated into to a single generation tone. The settings includes Frequency(Hz) and Amplitude(V) for each tone.

    It is recommended to select the Frequency(Hz) of each tone to be a integral multiple of (1/Generation Time(s)). So that complete cycle of each tone is present in the generated tone.

    In other words, each tone Frequency(Hz) should be a integral multiple of Fs/N. Where Fs is the "Sampling Rate" and "N" is the number of samples.

    The VI might throw an error if any frequency does not follow the above rule.

      		Tone Settings

      Tone Settings configures the requried settings to generate a tone which includes frequency (Hz) and amplitude (V)

        		Frequency (Hz)

        Frequency (Hz) represents generated waveform frequency in Hertz

        		Amplitude (V)

        Amplitude (V) represents the generated waveform amplitude in Voltage.

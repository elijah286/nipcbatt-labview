 Trigger Settings

<b>Trigger Settings</b> configures the analog voltage output task to start generation on the configured trigger.

Select <b>No Trigger</b> in case of immediate generate. Skip <b>Digital Start Trigger Source</b> and <b>Digital Start Trigger Edge</b>

Select <b>Digital Start</b> for triggered generate. Required Fields: <b>Digital Start Trigger Source</b> and <b>Digital Start Trigger Edge</b>

    		Digital Start Trigger Source[Digital Start Trigger Source]

    Digital Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

    Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

    		Digital Start Trigger Edge[Digital Start Trigger Edge]

    Edge specifies on which edge of the digital signal to start acquiring or generating samples.

    		Trigger Type

    The Trigger Type control selects which trigger type you wish to use. Depending on the selection, when you run the measurement/generation, the task will configure the desired trigger type.

    Note that not all hardware supports triggering--refer to your device documentation for more info.

Range and Terminal Settings

Applicable for "Configure & Measure" & "Configure Only"

Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

Specific Channel Settings the range and terminal settings for the physical analog input voltage channels. If the channels are not specified in the list, the global settings will be applied.

    		Global Settings

    Global Settings configures the range and terminal settings for all analog input voltage channels except the channels specified in the specific channel settings

      		Min Range (A)

      Min Range specifies the minimum value you expect to measure.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Max Range (A)

      Max Range specifies the maximum value you expect to measure.

      This value is used to help determine the range of the ADC. The actual range will be coerced to one that your hardware supports. Refer to your device documentation for a list of available ranges.

      		Terminal Configuration

      Terminal Configuration specifies the input terminal configuration for the channel.

      		Shunt Resistor (Ohm)

      Shunt Resistor specifies in ohms the resistance of an external shunt resistor connected to the output terminal.

    		Specific Channel Settings

error out

error out passes error or warning information out of a VI to be used by other VIs.

Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code

    code is the error or warning code.

    Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source

    source string describes the origin of the error or warning.

    Right-click the error out indicator on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

DC and RMS Current Measurements

DC-RMS Measurements specifies Average DC Current and RMS Current measurements for each channels.

    		Average DC Current (A)

    Average DC Current is the average measured DC current values. List contains values for each channels.

      		Average DC Current (A)

      Average DC Current is the average measured DC current values of the current waveform measured from a single channel.

    		RMS Current (A)

    RMS Current is the measured RMS value of the measured waveform. List contains values for each channels.

      		RMS Current (A)

      RMS Current is the measured RMS value of the current waveform measured from a single channel.

Current Waveforms[Current Waveforms]

Current Waveforms displays the most recent acquired data. If the output is disabled, the data read will be NaN, and the graph will be blank for those points.

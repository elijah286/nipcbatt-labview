DAQ_Digital Edge Count Measurement.lvlib:Wait Type.ctl

Wait Type specifies whether to use a software wait or hardware window.

Software Wait Type - Initiates the counting operation, waits for the duration specified and reads the current value of the counter. Use it for low frequency operations. If the Execution option is Measure Only, It will return the counter value immeditely and do not wait for the specified duration. User has to introduce the required delay between Configure Only and Measure Only calls.

Hardware Wait Type - Creates a measurement window using the Timer task. It will provide a precise edge counting for the specifed duration. Use this for high frequency operations.

error in describes error conditions that occur before this node runs. This input provides standard error in functionality.

Frequency Domain Measurements[Frequency Domain Measurements]

Frequency Domain Measurements specifies RMS Magnitude, Peak Magnitude, Detected tones in the FFT spectrum for each channels.

    		Magnitude RMS (dBV)

    Magnitude RMS (dBV) returns the rms magnitude of the FFT spectrum across the frequency scale. The unit of rms magnitude will be dBV.

    		Magnitude Peak (dBV)

    Magnitude Peak (dBV) returns the peak magnitude of the FFT spectrum across the frequency scale. The unit of peak magnitude will be dBV.

    		Detected Tones

    Detected Tones returns all the tones observed across channels configured

      		Detected Tones

      Detected Tones returns detected array of frequency and amplitude in the multi tone signal/waveform.

      Note: Each index/element in Frequency and Amplitude array corresponds to a single sine tone, both arrays are mapped linearly.

        		Frequencies (Hz)

        Frequencies (Hz) returns the array of frequency detected in the input signal/waveform.

        Note: Refer Amplitudes (V) for corresponding amplitude of the same tone.

          		Frequency

          Frequency of the detected single tone in Hz.

        		Amplitudes (V)

        Amplitudes (V) returns the array of Amplitude detected in the input signal/waveform.

        Note: Refer Frequencies (Hz) for corresponding frequency of the same tone.

          		Amplitude

          Amplitude of the detected single tone in V.

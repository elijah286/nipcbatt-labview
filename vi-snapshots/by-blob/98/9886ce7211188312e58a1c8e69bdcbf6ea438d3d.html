 Thermistor Parameters

Specifies the parameters used to derive temperature measurements for NTC typed thermistor.

    		Type

    Selects the type of thermistor parameters to be considered for temperature measurement. The Options are -

    A B C - Specifies the Steinhart–Hart parameters for the specified thermistor. The parameters includes A, B and C constants.

    Beta - Specifies the B (Beta) parameters for the Thermistor.

    		ABC Parameters

    Specifies the Steinhart–Hart parameters for the specified thermistor. The parameters includes A, B and C constants which are used to derive Temperature measurements.

    Note: Refer the Thermistor Datasheet to determine these parameter values.

      		A

      A is the A constant for the Steinhart–Hart equation.

      		B

      B is the B constant for the Steinhart–Hart equation.

      		C

      C is the C constant for the Steinhart–Hart equation.

    		Beta Parameters

    Specifies the B (Beta) parameters for the Thermistor which are used to derive Temperature measurements.

    Note: Refer the Thermistor Datasheet to determine these parameter values.

      		Beta Value (K)

      Specifies the Beta Value in Kelvin for the specified NTC Thermistor.

      		R0 (Ohm)

      Specifies the Nominal Resistance (R0) in Ohms for the specified NTC Thermistor measured at 25 degC.

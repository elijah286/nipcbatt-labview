Function Settings

Sets the particular function, range, and resolution of the measurement.

    		Resolution in Digits[Resolution in Digits]

Timing and Trigger Settings[Timing and Trigger Settings]

Aperture Time specifies the length of time during which the ADC is reading the signal.

Settle Time is the time required for a measurement system to stabilize to a specified accuracy limit.

AC Min Frequency specifies the minimum frequency the DMM uses for AC measurements.

Trigger Settings will be used to configure the source, delay, and slope of a hardware trigger if the user has an active trigger. Ensure the Enable Trigger? button is set to TRUE if using a trigger.

    		AC Min Frequency (Hz)[AC Min Frequency (Hz)]

    Specifies the minimum expected frequency component of the input signal in hertz.

    		Aperture Time (s)

    Specifies the length of time during which the ADC is reading the signal.

    		Settle Time (s)

    The time required for a measurement system to stabilize to a specified accuracy limit.

    		Trigger Settings

      		Trigger Delay (s)[Trigger Delay (sec)]

      Specifies the time the DMM waits after it has received a trigger before taking a measurement.

      		Enable Trigger?

      Set this button to TRUE if using a hardware trigger.

      		Trigger Source

      Selects the hardware trgger which will be used to trigger a measurement.

      		Slope[Slope]

      Specfies the direction of a signal that causes a trigger to occur.

Signal Generation Settings[Signal Generation Settings]

Signal Generation Settings contains the required configuration for signal generation. The configuration can generate both single tone and multi tone signals for a defined generation time(s). The Single tone signals supports both sine and square waves.

    		Generation Type[Generation Type]

    Generation Type specifies the type of tone to generate by DAQmx analog output

    		Generation Time (s)[Generation Time (s)]

    Generation Time (s) is the time for the generation of the single/multi-tone waveform.

    It is recommended to select the generation time (s) as an integral multiple of the time period (1/Frequence (Hz)) such that complete cycles of each tone are generated.

    For Multitone Generation, it is required that the generation time (s) is an integral multiple of the time period (1/Frequence (Hz)) of all the tones

    		Voltage Offset (v)[Voltage Offset (v)]

    Voltage Offset (s) represents the offset voltage to apply on the ouput generated waveform in the analog output channels.

    		Single Tone Settings[Single Tone Settings]

    Digital Start Trigger Setting configures the analog input measurement to start acquisition on digital edge trigger from source terminal

      		Waveform Type[Waveform Type]

      Waveform Type specifies the type of waveform to generate in a single tone method. It supports sine wave and square wave generation.

      		Frequency (Hz)[Frequency (Hz)]

      Frequency (Hz) represents the frequency in Hertz for the generated waveform.

      		Amplitude (V)[Amplitude (V)]

      Amplitude (V) represents the amplitude in Volts for the generated waveform.

      		Duty Cycle (%)[Duty Cycle (%)]

      Duty Cycle (%) represents the duty cycle in percentage(%) units for the generated waveform. This option is only applicable for Square waveform generation.

    		Multi Tone Settings[Multi Tone Settings]

    Multi Tone Settings allows to enter multiple tone settings which are integrated into to a single generation tone. The settings includes Frequency(Hz) and Amplitude(V) for each tone.

    Multi tone settings are applicable only for sine wave.

    It is recommended to select the Frequency(Hz) of each tone to be a integral multiple of (1/Generation Time(s)). So that complete cycle of each tone is present in the generated tone.

    In other words, each tone Frequency(Hz) should be a integral multiple of Fs/N. Where Fs is the "Sampling Rate" and "N" is the number of samples.

    The VI might throw an error if any frequency does not follow the above rule.

      		Tone Settings

      Tone Settings configures the requried settings to generate a tone which includes frequency (Hz) and amplitude (V)

        		Frequency (Hz)

        Frequency (Hz) represents generated waveform frequency in Hertz

        		Amplitude (V)

        Amplitude (V) represents the generated waveform amplitude in Voltage.

Routing paths

Routing paths specifies the list of paths between exported signal and output terminals where routing actions are performed.

    		Routing Path

    Routing Path routes a control signal to the specified output terminal. The route can carry a variety of digital signals, such as triggers and clocks.

      		Signal

      Signal specifies the device signal to export.

      The available options are,

      Sample Clock - Clock the device uses to time each sample

      Start Trigger - Trigger that begins a measurement or generation

      These Signals are associated with the DAQmx Task provided in the input. Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible signals for routing.

      		Output Terminal

      Output Terminal is the destination of the exported signal.

      Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible terminals for routing.

    		Out of Range

    		Unit

    String value dsiplaying the units of the measurement.

    		Measurement

    Contains the measurement captured by the DMM Read formatted into a single output string along with units.

DMM Execution Settings

This output cluster contains the values of all execution settings which were actually used by the driver during the measurement.

    		Absolute Resolution

    The smallest measurable increment that this DMM can detect.

    		Input Resistance (Ohm)

    The resistance presented by the DMM during the measurement.

    		Digits Resolution

    Indicates the number of digits displayed on the digital multimeter's readings.

    For example, for 5 digits, 00000 ~ 99999 can be displayed, but for 5 ½, this can be displayed when 000000 ~ 199999 are displayed. In other words, if ½ is used, it is used when the first digit is represented by only 0,1

    		Range

    The window of possible values that could be captured with this measurement.

    		Minimum Frequency (Hz)

    The minimum frequency component of the input signal parameter used during AC measurements.

    		Aperture Time (s)

    Value used during execution for the length of time for which the ADC was reading the signal.

    		Auto Range Value

    If auto range was used, displays the range that was selected by the automatic range finder and then used in the measurement.

    		Settle Time (s)

    Value used during execution by the full system needed to reach the specified accuracy limit.

    		Function

    Displays the type of measurement that was executed.

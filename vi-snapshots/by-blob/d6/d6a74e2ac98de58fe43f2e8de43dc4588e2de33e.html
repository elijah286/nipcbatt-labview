Timing and Trigger Settings[Timing and Trigger Settings]

Aperture Time specifies the length of time during which the ADC is reading the signal.

Settle Time is the time required for a measurement system to stabilize to a specified accuracy limit.

AC Min Frequency specifies the minimum frequency the DMM uses for AC measurements.

Trigger Settings will be used to configure the source, delay, and slope of a hardware trigger if the user has an active trigger. Ensure the Enable Trigger? button is set to TRUE if using a trigger.

    		AC Min Frequency (Hz)[Aperture Time (s)]

    Only used for AC measurements, specifies the minimum expected frequency component of the input signal in hertz. This parameter will help to calculate the proper aperture time of the DMM.

    		Settle Time (s)

    Forces the value for the length of time during which the ADC is reading the signal. The DMM will automatically calculate this value. Modifying the default value from automatic (-1) will impact the measurement speed but can reduce the accuracy.

    		Trigger Settings

    Forces the value of the length of time required for a measurement system to stabilize to a specified accuracy limit. The DMM will automatically set this value. Modifying the default value from automatic (-1) will impact the measurement speed for a scan but can reduce the accuracy.

      		Trigger Delay (s)[Trigger Delay (sec)]

      Specifies the time the DMM waits after it has received a trigger before taking a measurement.

      		Enable Trigger?

      Set this button to TRUE if using a hardware trigger.

      		Trigger Source

      Selects the hardware trgger which will be used to trigger a measurement.

      		Slope[Slope]

      Specfies the direction of a signal that causes a trigger to occur.

DMM Execution Settings

This output cluster contains the values of all execution settings which were actually used by the driver during the measurement.

    		Absolute Resolution

    The smallest measurable increment that this DMM can detect.

    		Input Resistance (Ohm)

    The resistance presented by the DMM during the measurement.

    		Digits Resolution

    Indicates the number of digits displayed on the digital multimeter's readings.

    For example, for 5 digits, 00000 ~ 99999 can be displayed, but for 5 ½, this can be displayed when 000000 ~ 199999 are displayed. In other words, if ½ is used, it is used when the first digit is represented by only 0,1

    		Range

    The window of possible values that could be captured with this measurement.

    		Minimum Frequency (Hz)

    The minimum frequency component of the input signal parameter used during AC measurements.

    		Aperture Time (s)

    Value used during execution for the length of time for which the ADC was reading the signal.

    		Auto Range Value

    If auto range was used, displays the range that was selected by the automatic range finder and then used in the measurement.

    		Settle Time (s)

    Value used during execution by the full system needed to reach the specified accuracy limit.

    		Function

    Displays the type of measurement that was executed.

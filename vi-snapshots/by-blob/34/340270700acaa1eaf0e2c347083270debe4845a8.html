 DC and RMS Voltage Measurements

DC Voltage Measurements specifies Average DC Voltage and RMS Voltage measurements for each channels.

    		Average DC Voltage (V)

    Average DC Voltage is the average measured DC voltage value. List contains values for each channels.

      		Mean DC Voltage (V)

      DC value is the measured DC value in volts if the signal is in volts.

    		RMS Voltage (V)

    RMS Voltages is the measured RMS value of the measured waveform. List contains values for each channels.

      		RMS Voltage (V)

      RMS values is an array of the measured RMS values.

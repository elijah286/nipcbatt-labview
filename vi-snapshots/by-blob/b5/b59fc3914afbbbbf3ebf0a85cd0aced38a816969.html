DAQ_Digital Pulse Generation.lvlib:DAQ_Digital Pulse Gen Initialize.vi

Initialize counter output channel and obtains a DAQmx task. Get Physical/Global channel of counter and output terminal to generate.

Note: Multiple counters cannot be initialized in the same task. Use a separate task for each counter.

Physical Channel (Counter)

Physical Channel specifies the name of the physical channel(counter) to use to create virtual channels.

The DAQmx physical channel control lists all physical channels on devices and modules installed in the system.

Note : Multiple Counters cannot be initialized in a single task

Output Terminal

Output Terminal specifies the output terminal on which to export the counter output signal.

Global Channel (counter)

Global Channel specify Global channels configured in the NI Max to use it instead of initiating a new task using physical channels specified.

Note : Global channel should be declared as Counter Output - Pulse Output. Global channel settings will be overwritten by Configure and Measure VI.

DAQmx Task Out[DAQmx Task Out]

DAQmx Task Out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to DAQmx Task Out, NI-DAQmx automatically creates the task this output refers to.
